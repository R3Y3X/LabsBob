Creación de Agentes y Herramientas MCP

Importa y despliega agentes especializados en watsonx Orchestrate conectados a herramientas MCP para consulta de inventario y catálogo.

Paso 1 — Crear la herramienta MCP y el agente de disponibilidad

En este paso vas a crear el primer agente del lab: SKU Availability Agent. Este agente consulta la disponibilidad de productos en tiempo real a través de una herramienta MCP.

1.1. Importar la herramienta MCP

Una herramienta MCP expone una función externa para que un agente pueda invocarla. En este caso, la herramienta ejecuta get_sku_availability.py, que consulta disponibilidad de inventario usando Kafka y ksqlDB.

Desde la terminal en la carpeta Lab2, ejecutá:

orchestrate toolkits add --kind mcp --name "sku-availability-checker" --description "Verificador de disponibilidad de inventario en tiempo real usando Confluent Kafka y ksqlDB" --language python --package-root "confluent_agents" --command "python get_sku_availability.py" --tools "get_sku_availability"

1.2. Importar y desplegar el agente

El archivo sku-availability-agent.yaml define el comportamiento del agente. Ejecutá:

orchestrate agents import -f confluent_agents/sku-availability-agent.yaml
  1. Ingresá a la interfaz de watsonx Orchestrate y dirigite a Build.
  2. Buscá el agente SKU_Availability_Agent.
  3. En la esquina superior derecha, hacé clic en Deploy y confirmá.

Paso 2 — Crear el agente RAG para encontrar sustitutos

En este paso vas a crear el Substitute Finder Agent. Este agente no consulta inventario en tiempo real; su función es razonar sobre el catálogo de productos para encontrar alternativas similares cuando un SKU no está disponible.

2.1. Importar y desplegar el agente

Desde la terminal en Lab2, ejecutá:

orchestrate agents import -f confluent_agents/Substitute_Finder_Agent.yaml

Luego, en la UI de watsonx Orchestrate, abrí el agente Substitute_Finder_Agent y hacé clic en Deploy.

2.2. Crear la base de conocimiento

El archivo product-catalog.docx representa un catálogo interno de productos. El agente lo usa como fuente de conocimiento.

  1. Dentro del agente Substitute_Finder_Agent, ingresá a la sección Knowledge y hacé clic en Add source.
  2. Seleccioná la opción para crear una nueva base de conocimiento.
  3. Seleccioná la opción Upload files y subí product-catalog.docx.
  4. Usá el nombre enterprise_documents y guardá. Esperá hasta que finalice la indexación.

Probar el agente

Probá una recomendación por similitud en la interfaz de chat del agente:

"LAPTOP-DELL-XPS-15 no está disponible. Sugerí una laptop similar usando el catálogo de productos."

El agente debe recomendar una laptop similar del catálogo y explicar brevemente qué atributos comparte.
