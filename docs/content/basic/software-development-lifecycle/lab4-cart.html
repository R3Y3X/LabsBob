Lab 04 — Construir el carrito y el checkout

6–12 BobCoins
~25 minutos

La última pantalla. En este lab vas a implementar el carrito para que coincida con mockups/cart.png, mostrar un resumen del pedido y conectar el botón Place order a la API para que devuelva una confirmación.

Lo que vas a construir

  • src/pages/Cart.jsx — ítems del pedido con selectores de cantidad, un resumen de la orden y un botón de checkout que llama a createOrder() y muestra una confirmación.
  • El estado de carrito vacío.

Antes de empezar

Labs 02–03 completos: puedes agregar productos al carrito desde la grilla y desde la página de producto. Agrega un par de ítems al carrito primero, así tienes datos con los que trabajar. Quédate en Agent Mode.

El objetivo

Adjunta el mockup al chat de Bob

Antes de los prompts de abajo, adjunta mockups/cart.png al chat de Bob para que construya a partir de la captura real.

Paso 1 — Construye el carrito y el resumen

Implementa src/pages/Cart.jsx para que coincida con mockups/cart.png. Reemplaza el
marcador de posición.

Lee el carrito desde useCart(): { items, subtotal, setQty, removeItem, clear }.

Layout: un título de página "Your cart", después dos columnas en desktop (artículos a la
izquierda, resumen del pedido a la derecha), apilado en mobile.

Artículos (izquierda): para cada uno muestra una imagen chica (imageUrl(item.image)), la
categoría, el nombre, el precio unitario, un selector de cantidad que llame a
setQty(item.id, newQty), el total de la línea (precio × cantidad) y un link "Remove" que
llame a removeItem(item.id).

Resumen del pedido (derecha, en una tarjeta): Subtotal (= subtotal de useCart), Shipping
mostrado como un "Free" en verde, un impuesto estimado del 8% del subtotal (redondeado) y
un Total = subtotal + impuesto. Después un botón de ancho completo "Place order" y la
línea "No account needed · orders confirm instantly".

Estado vacío: cuando items está vacío, muestra un mensaje amable y un botón que enlace de
vuelta a "/".

Usa los tokens de Tailwind de café. Importa imageUrl de ../api/client y useCart de
../cart/CartContext.

Escribe el código y todos los textos visibles de la UI en inglés, exactamente como
aparecen en el mockup. No traduzcas la interfaz.

No modifiques src/api/client.js. No agregues dependencias.

Paso 2 — Conecta el checkout

Haz que el botón "Place order" complete la compra:
- Al hacer clic, llama a
  createOrder({ items: items.map(i => ({ id: i.id, quantity: i.quantity })) })
  de ../api/client.
- Mientras el request está en vuelo, deshabilita el botón y muestra "Placing order…".
- Si tiene éxito, muestra un estado de confirmación que reemplace al carrito: un ícono de
  check, "Order confirmed!", el orderId devuelto, el total y el estimatedDelivery, más un
  botón "Continue shopping" que enlace a "/". Después llama a clear() para vaciar el
  carrito.
- Si falla, muestra un mensaje de error chico y vuelve a habilitar el botón.

La API siempre tiene éxito, así que el camino feliz es el que importa — pero maneja el
caso de error con elegancia igual.

Escribe el código y todos los textos visibles de la UI en inglés, exactamente como
aparecen en el mockup. No traduzcas la interfaz.

Paso 3 — Ejecuta y verifica

  1. Agrega ítems desde la tienda y desde la página de producto.
  2. Abre el carrito (el ícono de carrito en el header).
  3. Cambia cantidades: se actualizan los totales de línea, el subtotal, el impuesto y el total. Quitar el último ejemplar de un ítem elimina la línea.
  4. Con 1 × Ethiopia Yirgacheffe y 2 × Daybreak Blend, el resumen debería mostrar Subtotal $49 · Tax $4 · Total $53 — igual que el mockup.
  5. Haz clic en Place order → obtienes una confirmación con un orderId (por ejemplo BB-7QF2K9) y el carrito se vacía (el badge del header vuelve a 0).
  6. Vacía el carrito y confirma que se muestre el estado vacío.

Checkpoint

Puedes armar un carrito, ver los totales correctos, hacer un pedido y recibir una confirmación: el flujo completo de la tienda funciona de punta a punta.

Solución de problemas

Los totales no se actualizan cuando cambio la cantidad

El selector tiene que llamar a setQty(item.id, newQty) de useCart() (no a un estado local). El subtotal de useCart() se recalcula automáticamente cuando cambia el carrito.

El pedido falla / no pasa nada al hacer clic en Place order

Abre la consola. Confirma que la URL de la API esté configurada y que <API_URL>/api/orders sea alcanzable. El cuerpo del request debería ser { items: [{ id, quantity }] }. Recuerda que Vite lee .env solo al arrancar: reinicia npm run dev después de cambiarlo.

El carrito se vacía pero la confirmación desaparece al refrescar

Es lo esperable: la confirmación es estado de pantalla. Habría que impedir volver a ejecutar el checkout desde un carrito vacío (deshabilita Place order cuando no hay artículos).

Criterios de éxito

  • Cart.jsx lista los ítems con selectores de cantidad y opción de quitar funcionando.
  • El resumen del pedido muestra subtotal, envío gratis, 8% de impuesto y total.
  • Place order llama a createOrder() y muestra una confirmación con el orderId.
  • El carrito se vacía después de un pedido exitoso; el estado vacío se renderiza.
  • La página se parece a cart.png.
