Agente RAG de sustitutos

Importa el Substitute Finder y conéctalo al catálogo de productos.

Crear el agente RAG para encontrar sustitutos

El Substitute Finder Agent no consulta inventario en tiempo real: razona sobre el catálogo para encontrar alternativas cuando un SKU no está disponible.

Importar y desplegar el agente

Desde la terminal en Lab2, ejecuta:

orchestrate agents import -f confluent_agents/Substitute_Finder_Agent.yaml

En la UI de watsonx Orchestrate, abre Substitute_Finder_Agent y haz clic en Deploy.

Crear la base de conocimiento

El archivo product-catalog.docx es el catálogo interno. El agente lo usa como fuente.

  1. Dentro de Substitute_Finder_Agent, entra a Knowledge y haz clic en Add source.
  2. Crea una base de conocimiento nueva.
  3. Upload files y sube product-catalog.docx.
  4. Nómbrala enterprise_documents, guarda y espera a que termine la indexación.

Probar el agente

En el chat del agente:

"LAPTOP-DELL-XPS-15 no está disponible. Sugiere una laptop similar usando el catálogo de productos."

Debe recomendar una laptop similar y explicar qué atributos comparte.
