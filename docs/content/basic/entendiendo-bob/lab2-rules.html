Qué es una rule

Las rules son archivos de texto que Bob inyecta en todas las conversaciones, en todos los modos. Sirven para estándares de código, tono y restricciones de flujo, sin repetirlas en cada prompt.

Rules vs modo personalizado

Una rule no la pisa un modo personalizado. Si defines un monólogo interno como rule global, seguirá aplicándose aunque uses Ask, Agent o un modo que tú creaste. Las rules son el mecanismo transversal; las instrucciones del modo cubren solo ese modo.

Las rules de proyecto viven en .bob/rules/ y se versionan con el código: todo el equipo las hereda al clonar el repositorio.
