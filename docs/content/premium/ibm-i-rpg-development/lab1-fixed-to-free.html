Paso 2 — Convierte a formato libre

IBM Bob · Agent

Pide la conversión con Dcl-Proc y revisa el resultado antes de aplicar cambios.

Pega en el chat de Bob

Convierte la subrutina s01lod (líneas 102-118) de formato fijo a formato libre.

Requisitos:
- Usa Dcl-Proc en lugar de BEGSR/ENDSR
- Mantén la misma lógica
- Añade comentarios explicando cada sección
- Usa sintaxis RPG IV moderna

Muéstrame el código convertido.

Respuesta ilustrativa

// Procedimiento de carga de subfile
Dcl-Proc LoadSubfile;

  // Restaurar posición del último read
  RestorePosition();

  // Inicializar subfile
  RRb01 = RRn01 + 1;
  opt01 = 0;
  count = 0;

  // Leer y cargar hasta 14 registros
  Read ARTICLE2;
  DoW Not %Eof(ARTICLE2) And count < 14;
    RRN01 += 1;
    count += 1;
    Write SFL01;
    Read ARTICLE2;
  EndDo;

  // Indicador de fin de fichero
  sflend = %Eof(ARTICLE1);
  step01 = dsp;

  // Guardar posición actual
  SavePosition();

End-Proc;
