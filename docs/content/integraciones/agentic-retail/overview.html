Agentic Retail — Real-Time Inventory with Confluent & watsonx Orchestrate

Bob wires a real-time Apache Kafka inventory pipeline on Confluent Cloud to a multi-agent system on watsonx Orchestrate. The result: a store associate AI agent that checks live stock and suggests RAG-powered alternatives when a product is out of stock — all built by Bob with minimal manual effort.

Prerequisites

  • IBM Bob IDE installed — free trial
  • watsonx Orchestrate instance (SaaS or Developer Edition ADK v2.1+)
  • Confluent Cloud account with access to Kafka — sign up
  • Python 3.10+ with pip
  • Confluent CLI installed
  • Basic familiarity with Kafka concepts (topics, consumers)

Rules & Considerations

Credentials required for Confluent and watsonx Orchestrate

You will need: Confluent Cloud Kafka Cluster ID, Bootstrap Server, API Key + Secret, ksqlDB Cluster credentials, and a watsonx Orchestrate API key. Store these in a local .env file — never commit it to source control.

Bob is optional but recommended

This lab can be completed manually following the steps below. Bob accelerates every step — from creating Kafka topics to generating MCP tool code and agent YAML files. The Bob prompts are provided for each step.
