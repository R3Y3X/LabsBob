Mensajes de Ejemplo — Publicación y Automatización

Publica eventos de prueba manualmente o mediante automatización con IBM Bob para alimentar el stream de inventario.

Paso 3. Publicar mensajes de ejemplo al tópico

En este punto ya tenemos creados dos tópicos:

  • inventory.transactions: Incluye todas las transacciones (positivo significa stock adicional, y negativo significa transacción de venta).
  • inventory.availability: Este es un tópico derivado que creamos en el paso anterior para calcular la disponibilidad automáticamente.

El tópico inventory.transactions existe pero no tiene mensajes. Tenemos que publicar mensajes en el tópico.

Publicar mensajes de manera manual

Para crear cada mensaje manualmente sería de esta manera:

  1. Acceder al tópico inventory.transactions desde el menú de la izquierda.
  2. Hacer click en Messages.
  3. Hacer click en Produce new message.
 {
  "sku": "LAPTOP-DELL-XPS-15",
  "branch": "Dot Shopping",
  "quantity": 50,
  "transaction_type": "ADDITION",
  "timestamp": "2025-12-29T08:00:00Z",
  "source": "inventory_manager",
  "reference": "PO-2025-001"
}

Automatizar con IBM Bob

Pero como queremos crear 20 mensajes de ejemplo, vamos a utilizar un script de Python ejecutado en la terminal.

  1. Abre una terminal integrada en tu IDE (si estás en Windows, asegúrate de que sea Git Bash y no PowerShell).
  2. Navega a la carpeta de este laboratorio:
cd Labs-tech-summit/Lab1/inventory-pipeline
  1. Ejecuta el script de configuración para inyectar los datos:
./setup.sh -s 3
  1. Verifica la creación desde la UI de Confluent: Accede al tópico inventory.transactions y haz click en Messages.

Criterios de Éxito

  • El tópico inventory.transactions existe con Partitions = 1 y Retention Time = infinite.
  • El stream inventory_transactions y la tabla inventory_availability están creados y corriendo en ksqlDB.
  • El tópico derivado inventory.availability se llena automáticamente al llegar transacciones.
  • Hay 20 mensajes de ejemplo publicados en inventory.transactions (visibles desde Messages en la UI).
