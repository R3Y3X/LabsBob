Laboratorio 4 — IBM i MCP y Bob Shell (opcional)

Conecta Bob con IBM i Agent y MCP para consultar el sistema y explorar objetos mediante lenguaje natural.

Requiere IBM i aprovisionado
~30 minutos
5–10 BobCoins estimados

Introducción

Nivel: Intermedio

Laboratorio opcional: requiere un entorno aprovisionado

Este laboratorio es opcional . Requiere un entorno IBM i aprovisionado con el servidor IBM i MCP (Mapepire en el puerto 8076) y acceso SSH en vivo. Si no tiene uno, puede omitir esta práctica de laboratorio de manera segura.

Requisitos previos

  • IBM Bob instalado y ejecutándose.
  • Acceso a un sistema IBM i con el servidor Mapepire en ejecución (puerto 8076).
  • Familiaridad básica con la línea de comando.

En esta práctica de laboratorio, configurará IBM Bob para que funcione con sistemas IBM i utilizando el protocolo de contexto modelo (MCP). Configurará modos personalizados, se conectará a su sistema IBM i y ejecutará sus primeras consultas utilizando la interfaz impulsada por IA de Bob.

El paquete IBM Bob premium para IBM i disponible en GA traerá modos y herramientas estándar de IBM i que diferirán de los utilizados en este tutorial.

lo que aprenderás

  • Cómo configurar Bob para el desarrollo de IBM i con MCP y modos.
  • Cómo utilizar las IA agent mode específicas de IBM i.
  • Cómo consultar sistemas IBM i utilizando lenguaje natural.
  • Cómo aprovechar las herramientas IBM i prediseñadas.

Configuración de laboratorio

Paso 1: abrir proyecto

Abra la carpeta lab4-ibmi-mcp en una nueva ventana de Bob; este es el directorio de trabajo del participante.

Paso 2: configurar la conexión de IBM i

Configure el reenvío de puertos para crear un túnel SSH entre el puerto local 8076 y el servidor IBM i:

$ Terminal integrada

        ssh -i PATH/TO/pem_user_privatekey_download.pem \
  -L 8076:localhost:8076 \
  -o ServerAliveInterval=15 \
  -o ServerAliveCountMax=3 \
  cecuser@<IBMi_IP_ADDRESS>

Cree un archivo .env en la raíz de su proyecto con sus credenciales de IBM i:

Archivo: .env

        DB2i_HOST=localhost
DB2i_USER=YOURUSER
DB2i_PASS=yourpassword
DB2i_PORT=8076

Paso 3: Verifique la configuración

  1. Abre la configuración de Bob.
  2. Verifique que ℹ️ IBM i Agent y ℹ️ IBM i MCP Tool Builder aparezcan en su lista de modos.
  3. Comprueba que ibmi-mcp-server y ibmi-mcp-docs aparecen conectados en tu lista MCP.

Ejercicio 1: cambiar al modo IBM i Agent

Objetivo : seleccione el agente de IA específico de IBM i.

  1. Cambiar al modo IBM i Agent.

  2. Pregúntale a Bob: What can you help me with?

    • Bob debería describir sus capacidades de IBM i.
    • Es posible que deba volver a cargar la ventana para actualizar las credenciales del servidor MCP: Cmd + Shift + P , buscar Developer: Reload Window .

Ejercicio 2: Consultar el estado del sistema

Objetivo : utilice Bob para comprobar el rendimiento de su sistema IBM i.

  1. Pregúntale a Bob: Show me the current system status .
  2. Bob debería ejecutar la herramienta system_status y mostrar:
    • Información del sistema
    • Actividad laboral
    • Procesamiento de recursos
    • Memoria y almacenamiento
    • Tabla de Trabajos
    • Configuración del sistema

Preguntas adicionales para probar:

  • What is the current CPU usage?
  • How many jobs are currently active?
  • Show me memory pool information

Ejercicio 3: explorar objetos de base de datos

Objetivo : use Bob para explorar su base de datos IBM i.

  1. Pregúntale a Bob: List all service categories available on IBM i .
    • Bob debería mostrar categorías como "Administración del sistema", "Rendimiento", "Seguridad", etc.
  2. Pregúntale a Bob: Search for services related to 'job' in their name .
    • Bob debe enumerar los servicios SQL relacionados con el trabajo.

Preguntas adicionales para probar:

  • What services are available in the Performance category?
  • Show me an example of using the ACTIVE_JOB_INFO service
  • List tables in the QSYS2 schema

Ejercicio 4: Análisis de seguridad

Objetivo : use Bob para realizar una verificación de seguridad básica.

  1. Pregúntale a Bob: Show me users with limited capabilities .
    • Bob debería ejecutar la herramienta de seguridad y mostrar los resultados.
  2. Pregúntale a Bob: Are there any database files readable by any user? .

Solución de problemas

MCP la conexión del servidor falla
  • Verifique que el archivo .env tenga las credenciales correctas.
  • Asegúrese de que Mapepire se esté ejecutando en IBM i (puerto 8076).
  • Probar conectividad: ping your-ibmi-hostname .
  • Verifique que el firewall permita el puerto 8076.
Las herramientas devuelven errores
  • Verifique que su usuario de IBM i tenga las autoridades adecuadas.
  • Verifique los registros del servidor Mapepire en IBM i.
  • Asegúrese de que los servicios QSYS2 estén disponibles en su sistema.
No se devolvieron datos
  • Confirme que está consultando objetos/esquemas existentes.
  • Verifique la sintaxis SQL en las definiciones de herramientas.
  • Verifique las autoridades de la base de datos para su perfil de usuario.

Paso 2: actualice la configuración MCP para CLI

Bob CLI puede requerir algunos cambios en la configuración MCP. Actualice su .bob/mcp.json :

Encuentre la ruta completa a npx:

$ Terminal integrada

        which npx
# Example output: /opt/homebrew/bin/npx

Obtenga la ruta completa al directorio de su proyecto:

$ Terminal integrada

        pwd
# Example output: /Users/yourname/bob-ibmi-lab

Actualice .bob/mcp.json con rutas completas, por ejemplo:

Archivo de configuración · JSON

        {
    "mcpServers": {
        "ibmi-mcp-server": {
            "command": "npx",
            "args": [
                "@ibm/ibmi-mcp-server",
                "--tools",
                "/Users/liampatty/Documents/bob/bob sldc/bob-for-rpg-workflow/test-lab4-ibmi-mcp/.bob/tools"
            ],
            "cwd": "/Users/liampatty/Documents/bob/bob sldc/bob-for-rpg-workflow/test-lab4-ibmi-mcp",
            "env": {
                "NODE_OPTIONS": "--no-deprecation --no-warnings",
                "MCP_TRANSPORT_TYPE": "stdio",
                "YAML_ALLOW_DUPLICATE_SOURCES": "true"
            },
            "disabled": false,
            "alwaysAllow": []
        },
        "ibmi-mcp-docs": {
            "type": "streamable-http",
            "url": "https://ibm-d95bab6e.mintlify.app/mcp"
        }
    }
}

Referencia de opciones CLI

Opciones comunes de Bob CLI:

  • --chat-mode <mode> : especifica el modo de chat: plan , code , ask o advanced .
  • --hide-intermediary-output : suprime la producción adicional, muestra solo los resultados finales.
  • --max-coins <number> : establece el límite de costo máximo (sale con el código 1 si se excede).
  • --help : muestra todas las opciones disponibles.
