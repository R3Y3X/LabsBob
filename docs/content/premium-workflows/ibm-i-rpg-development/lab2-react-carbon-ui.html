Laboratorio 2 — Interfaz React + Carbon

Construye una lista web moderna con React y Carbon a partir de datos de artículos.

Objetivo Interfaz web
~30 minutos
4–10 BobCoins estimados
Premium acceso requerido

Introducción

Utilice IBM Bob para crear una interfaz web moderna para mostrar artículos desde cero. No se necesita conexión IBM i: usaremos datos de muestra.

lo que construirás

Una aplicación React independiente con lista de artículos y funcionalidad de búsqueda.

Requisitos previos

  • Node.js instalado (v18+)
  • Conocimientos básicos del desarrollo web.

Caso de uso: mostrar lista de artículos

Crearemos una aplicación React completa desde cero que muestra artículos en una tabla con funcionalidad de búsqueda, similar a la pantalla verde pero moderna y responsiva.

Paso 0: Pon a Bob en modo code

En esta práctica de laboratorio, Bob crea el proyecto y escribe archivos, así que cambie del modo ask al modo code antes de comenzar. Expanda el menú desplegable de modos debajo de la entrada del chat y seleccione Código .

Paso 1: crea un nuevo proyecto React

Pregunta para Bob: 

        Cree un nuevo proyecto React + TypeScript usando Vite con Carbon Design System.

Requisitos:
- Nombre del proyecto: artículo-list-app
- Utilice Vite para un desarrollo rápido
- Incluir mecanografiado
- Instalar el sistema de diseño Carbon (@carbon/react)
- Instalar estilos Carbon
- Configurar la estructura básica del proyecto.

Cree el proyecto en el directorio actual.

la respuesta de bob

Bob crea un nuevo proyecto React con:

  • Configuración de invitación
  • Configuración de mecanografiado
  • Carbon Sistema de diseño instalado
  • Estructura de carpetas básica ( src/ , public/ , etc.)

Alternativa manual (si es necesario): 

        npm create vite@latest article-list-app -- --template react-ts

Paso 3: Pídale a Bob que cree datos de muestra

Pregunta para Bob: 

        Cree un archivo TypeScript con 10 artículos de muestra basados en la estructura ART400.

Cada artículo debe tener:
- id (6 caracteres como "ART001")
- descripción (50 caracteres)
- familyCode (3 caracteres como "ELE")
- familyDescription (como "Electrónica")
- precio de venta (número)
- acciones (número)

Guárdalo como: article-list-app/src/data/sampleArticles.ts

la respuesta de bob

Bob crea un archivo con datos de muestra que puede utilizar para el desarrollo.

Paso 4: Pídale a Bob que cree el componente de lista de artículos

Pregunta para Bob: 

        Cree un componente React que muestre artículos en una tabla de datos Carbon.

Requisitos:
- Utilice el componente Carbon Design System DataTable
- Mostrar columnas: ID, Descripción, Familia, Precio, Stock
- Agregue un cuadro de búsqueda en la parte superior
- Utilice los datos de muestra de sampleArticles.ts
- Manténgalo simple: solo muestre, no hay edit/delete todavía

Guardar como: article-list-app/src/components/SimpleArticleList.tsx

  • Carbon Tabla de datos

Paso 5: Pídale a Bob que configure la aplicación principal

Pregunta para Bob: 

        Actualice article-list-app/src/App.tsx para mostrar el componente SimpleArticleList.

Requisitos:
- Importar estilos Carbon (@carbon/styles/css/styles.css)
- Importar el componente SimpleArticleList
- Muéstralo en la aplicación principal con Carbon Tema
- Añadir un título "Gestión de artículos"
- Utilice el tema blanco de Carbon

la respuesta de bob

Bob actualiza App.tsx para mostrar su nuevo componente.

Paso 6: ejecutar y probar

Ejecutar la aplicación: 

        cd article-list-app
      
        npm run dev

Pruébalo:

  1. Abra el navegador en http://localhost:5173 (o la URL que se muestra en la terminal).
  2. Vea la lista de artículos mostrada.
  3. Prueba el cuadro de búsqueda.
  4. Verifique que los datos se muestren correctamente.
  5. Pruebe el diseño responsivo cambiando el tamaño del navegador.

Criterios de éxito

Ha completado con éxito esta práctica de laboratorio cuando:

  • Nuevo proyecto React creado desde cero
  • Puedes ver el diseño de la pantalla verde (Paso 2)
  • Archivo de datos de muestra creado
  • La lista de artículos se muestra en el navegador

Conclusiones clave

  1. Desarrollo independiente : creaste una aplicación React completa desde cero.
  2. Bob ayuda a visualizar : pídele a Bob que te muestre la pantalla heredada.
  3. Datos de muestra primero : comience con datos simulados, conéctese a la API real más tarde.
  4. Carbon componentes : componentes de interfaz de usuario profesionales prediseñados.
  5. Desarrollo incremental : comience de manera simple, agregue funciones más adelante.
