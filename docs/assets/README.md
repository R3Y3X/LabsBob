# Asset Guidelines

This folder contains the static assets used by the GitHub Pages site.

## Structure

- [`images/`](docs/assets/images) for shared visual assets and lab imagery
- [`icons/`](docs/assets/icons) for small interface graphics if they are added later

## Naming

- Use lowercase names
- Separate words with hyphens
- Group lab-specific files under a folder that matches the lab slug

Example:

- `images/hands-on-inicial/hero-overview.png`
- `images/agentic-retail/architecture-diagram.png`
