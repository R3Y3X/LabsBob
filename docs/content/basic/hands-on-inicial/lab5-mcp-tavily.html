LAB 5 — Conecta IBM Bob al Mundo: MCP con Tavily

MCP (Model Context Protocol) es el sistema que permite a IBM Bob conectarse con herramientas externas. En este lab configurarás Tavily Search — una API de búsqueda optimizada para IA — para que IBM Bob pueda buscar información actualizada en internet en tiempo real desde Agent Mode.

Objetivos de Aprendizaje

  • ✅ Entender qué es MCP en palabras simples
  • ✅ Configurar Tavily Search API en IBM Bob
  • ✅ Conectar IBM Bob con herramientas externas
  • ✅ Realizar búsquedas web en tiempo real desde Agent Mode

¿Qué es MCP?

La Analogía Simple

Imagina que IBM Bob es un experto que solo habla español, y Tavily (búsqueda web) solo habla inglés.

  • Sin MCP: IBM Bob no puede buscar en la web ("no habla ese idioma")
  • Con MCP: El protocolo actúa como traductor — IBM Bob ahora accede al mundo exterior

MCP (Model Context Protocol) es un adaptador universal que conecta IBM Bob con herramientas externas. En este lab:

  • IBM Bob = Tu asistente de IA
  • MCP = El conector / traductor
  • Tavily = La herramienta externa de búsqueda web

MCP en Bob 2.1: Agent Mode lo hace todo

En Bob 2.1, Agent Mode tiene acceso nativo a MCP. Ya no es necesario un modo especial separado (como el anterior Advanced Mode). Simplemente activa Agent Mode y los servidores MCP configurados estarán disponibles.

Configuración Paso a Paso

Paso 1 — Obtener tu API Key de Tavily (gratis)

  1. Visita tavily.com
  2. Haz clic en "Sign Up" y crea una cuenta gratuita con tu email
  3. Verifica tu email
  4. Ve al Dashboard y copia tu API Key

Plan Gratuito de Tavily

El tier gratuito incluye 1,000 búsquedas/mes — más que suficiente para este lab y para experimentar.

Paso 2 — Configurar MCP en IBM Bob 2.1

En Bob 2.1, la configuración MCP tiene una pestaña dedicada en Ajustes — ya no es necesario editar JSON a mano (aunque sigue siendo posible):

  1. Abre IBM Bob
  2. Ve a Ajustes (Settings) → pestaña "MCP Servers"
  3. Haz clic en "Add Server" o usa la opción de edición directa del JSON

Opción A — JSON directo (si prefieres editar el archivo de configuración):

{
  "mcpServers": {
    "tavily": {
      "command": "npx",
      "args": ["-y", "tavily-mcp@latest"],
      "env": {
        "TAVILY_API_KEY": "PEGA_TU_API_KEY_DE_TAVILY_AQUI"
      }
    }
  }
}

⚠️ Reemplaza el placeholder con tu API Key real

Cambia PEGA_TU_API_KEY_DE_TAVILY_AQUI por la API key que copiaste de Tavily. NUNCA hagas commit de tu API key a Git.

Paso 3 — Guardar y Recargar

  1. Guarda la configuración
  2. Haz clic en el botón de recargar (⟳) en la pestaña MCP Servers
  3. Deberías ver Tavily apareciendo como herramienta disponible con estado activo
