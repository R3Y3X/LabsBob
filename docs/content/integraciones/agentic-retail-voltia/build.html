Prompt para Bob:

Implementa src/components/ProductCard.jsx para que coincida con una tarjeta de la
grilla en mockups/home.png.

- Recibe una prop `product` (ver el typedef Product en src/api/catalog.js).
- Muestra: el thumbnail (el emoji product.emoji centrado y grande sobre un
  degradado lineal que va de product.colors[0] a product.colors[1]), la categoría
  (etiqueta chica en mayúsculas), el nombre, el precio (usa formatPrice de
  ../api/client) y un botón "+" abajo a la derecha. El botón + es un CUADRADO

- Usa los tokens de Tailwind ya definidos: bg-white, border-line, rounded-card,

1. Construye el detalle de producto

Implementa src/pages/Product.jsx para que coincida con mockups/product.png.

Lo que vas a construir

La meta: mockups/cart.png. Quedate en 💻 Modo Código. (Antes de empezar, agrega un par de productos a la reserva, así tienes datos con qué trabajar.)

1. Construye el carrito

📎 Paso obligatorio — adjunta el mockup antes de enviar el prompt

Adjunta mockups/cart.png al chat de Bob antes de enviar este prompt (botón de agregar imagen, al lado del de enviar → carpeta mockups/). Igual que en la Parte 2: si abres la imagen en Bob primero, el selector se abre directo en mockups/.

Prompt para Bob:

Implementa src/pages/Cart.jsx para que coincida con mockups/cart.png. Reemplaza el
placeholder.

Lee la reserva con useCart(): { items, subtotal, setQty, removeItem, clear }.
Lee la sucursal con useBranch(): { branch }.

Layout: un título "Tu reserva", después dos columnas en desktop (líneas a la
izquierda, resumen a la derecha), apiladas en mobile.

Líneas (izquierda): para cada item muestra un thumbnail chico (emoji item.emoji
sobre degradado de item.colors), la categoría, el nombre, el precio unitario
(formatPrice), un selector de cantidad que llama setQty(item.id, nuevaCantidad), el

Resumen (derecha, en una tarjeta): primero una cajita con la "Sucursal de retiro"

línea "Sin pago online · pagas al retirar en la sucursal".

Estado vacío: cuando items está vacío, muestra un mensaje amable y un botón que
vuelve a "/".

Usa los tokens de Tailwind. Importa formatPrice de ../api/client, useCart de
../cart/CartContext y useBranch de ../branch/BranchContext. No modifiques
src/api/client.js. No agregues dependencias.

2. Conecta el checkout

Prompt para Bob:

Haz que el botón "Confirmar reserva" funcione:
- Al hacer clic, llama createReservation({ store: branch, items: items.map(i => ({
  id: i.id, quantity: i.quantity })) }) de ../api/client.
- Mientras la petición está en curso, deshabilita el botón y muestra "Confirmando…".
- Al confirmar, muestra un estado de confirmación que reemplaza la reserva: un ícono
  de check, "¡Reserva confirmada!", el reservationCode devuelto, la sucursal de
  retiro (store), el total y el readyBy, más un botón "Seguir explorando" que vuelve
  a "/". Después llama clear() para vaciar la reserva.
- Si falla, muestra un mensaje de error chico y reactiva el botón.

La API siempre confirma, así que el camino feliz es el que importa — igual maneja
el error con elegancia.

3. Ejecuta y verifica

  1. Agrega productos desde el storefront y la página de producto.
  2. Abre la reserva (el ícono del carrito en el header).
  3. Cambia cantidades — los totales de línea, el subtotal, los impuestos y el total se actualizan. Quitar el último de un item elimina la línea.
  4. El resumen muestra la sucursal elegida en el header (cámbiala y vuelve a la reserva para verlo).
  5. Toca Confirmar reserva → obtienes una confirmación con un reservationCode (como VOL-7QF2K9) y la reserva se vacía (el badge vuelve a 0).
  6. Vacía la reserva y confirma que se muestra el estado vacío.

Checkpoint

Puedes armar una reserva, ver los totales correctos, elegir sucursal, confirmar y obtener un código — el flujo completo de la tienda funciona de punta a punta.

Solución de problemas
  • Los totales no se actualizan al cambiar la cantidad. El selector debe llamar setQty(item.id, nuevaCantidad) de useCart() (no estado local). El subtotal de useCart() se recalcula solo cuando cambia el carrito.
  • No pasa nada al confirmar. Abre la consola. El cuerpo debe ser { store, items: [{ id, quantity }] }.
  • La reserva se vacía pero la confirmación desaparece al refrescar. Es lo esperado — la confirmación es estado de pantalla. Deshabilita "Confirmar reserva" cuando no hay items.

Criterios de éxito

  • Cart.jsx lista las líneas con selectores y "Quitar" funcionando.
  • El resumen muestra sucursal, subtotal, retiro gratis, impuestos 8 % y total.
  • Confirmar reserva llama createReservation() y muestra una confirmación con reservationCode.
  • La reserva se vacía tras confirmar; el estado vacío se renderiza.
  • La página se parece a cart.png.
