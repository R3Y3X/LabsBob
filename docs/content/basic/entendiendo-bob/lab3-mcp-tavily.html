¿Qué es MCP?

La Analogía Simple

Imagina que IBM Bob es un experto que solo habla español, y Tavily (búsqueda web) solo habla inglés.

  • Sin MCP: IBM Bob no puede buscar en la web ("no habla ese idioma")
  • Con MCP: El protocolo actúa como traductor — IBM Bob ahora accede al mundo exterior

MCP (Model Context Protocol) es un adaptador universal que conecta IBM Bob con herramientas externas. En este lab:

  • IBM Bob = Tu asistente de IA
  • MCP = El conector / traductor
  • Tavily = La herramienta externa de búsqueda web

MCP en IBM Bob: Agent Mode lo hace todo

Agent Mode tiene acceso nativo a MCP. Ya no es necesario un modo especial separado (como el anterior Advanced Mode). Simplemente activa Agent Mode y los servidores MCP configurados estarán disponibles.

Configuración Paso a Paso

Paso 1 — Obtener tu API Key de Tavily (gratis)

  1. Visita tavily.com
  2. Crea una cuenta gratuita y verifica el email
  3. En el Dashboard, copia tu API Key

Plan gratuito

1,000 búsquedas/mes — suficiente para el lab y experimentos.

Paso 2 — Configurar MCP en IBM Bob

  1. Ajustes → pestaña MCP Servers
  2. Add Server o edición directa del JSON

JSON de ejemplo:

{
  "mcpServers": {
    "tavily": {
      "command": "npx",
      "args": ["-y", "tavily-mcp@latest"],
      "env": {
        "TAVILY_API_KEY": "PEGA_TU_API_KEY_DE_TAVILY_AQUI"
      }
    }
  }
}

No subas la API key a Git

Reemplaza el placeholder por tu key real. Nunca hagas commit del secreto.

Paso 3 — Guardar y Recargar

  1. Guarda la configuración
  2. Pulsa recargar (⟳) en MCP Servers
  3. Confirma que Tavily aparece activo
