LAB 3 — UI Modernization (Struts → React)

Reemplaza el frontend Struts/JSP de Simple Pharmacy por una SPA en React (Vite + TypeScript), con backend JAX-RS en Liberty. Criterio de éxito: mvn clean compile (backend) + npm run dev arranca en localhost:5173 sin errores.

📋 Arquitectura Objetivo

Stack resultante

  • Backend: Liberty puerto 9081 — endpoints REST en /simple-pharmacy/api/*
  • Frontend: Vite dev server puerto 5173 — React + TypeScript
  • Comunicación: fetch con CORS habilitado en Liberty
