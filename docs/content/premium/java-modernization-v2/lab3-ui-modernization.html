Solución de problemas y ayuda

Solución de problemas

CWWKS9660E — orb element requires a user registry

Bob configuró jakartaee-10.0 completo, que arrastra el stack ORB/EJB. Esta app es REST + JSP — no usa EJB. Reemplaza en src/main/liberty/config/server.xml:

<feature>webProfile-10.0</feature>

Conserva features mpOpenAPI-* / mpMetrics-* si están. El snapshot enviado ya usa webProfile-10.0; esto solo reaparece si Bob lo cambió.

Todas las llamadas /api devuelven 404

Causa 1 — context root incorrecto (la más común). Si el WAR se despliega como simple-pharmacy.war, la base real es /simple-pharmacy.war/api/…. Fija context-root="/simple-pharmacy" en el elemento <webApplication> de server.xml y reinicia.

Causa 2 — Struts intercepta /api (solo si Struts sigue en web.xml). Pide a Bob:

Struts está interceptando /api antes de que JAX-RS lo vea. Añade la constante
struts.action.excludePattern para /api y confirma que existe la clase activadora
@ApplicationPath("/api"). El patrón debe ser .*/api/.*

El frontend no alcanza el backend — connection refused / CORS

  • Confirma que el backend responde: http://localhost:9081/simple-pharmacy/api/dashboard en el navegador → JSON
  • Ambos servidores deben correr a la vez: Liberty en 9081 y Vite en 3000
  • Si el navegador reporta CORS, pega el error en Bob — el CorsFilter generado es responsable de reconciliarlo

npm run dev falla o la página está en blanco

  • Confirma Node 20 o 22 LTS: node --version
  • Desde la carpeta frontend/, ejecuta npm install
  • Pega la salida de consola (navegador y terminal) en Bob

Páginas construidas pero sin datos (Fase 4+)

En la Fase 3 un scaffold vacío es normal. En la Fase 4+, si el shell React renderiza pero las tablas están vacías, abre DevTools → Network y recarga. Si las peticiones /api/… son 404:

curl http://localhost:3000/api/dashboard
  • JSON de vuelta → proxy y backend coinciden; el problema puede ser drift de nombres de campo
  • 404 → el proxy Vite (/api/* → /simple-pharmacy/api/*) y el context root de Liberty no coinciden. Fija context-root="/simple-pharmacy" en server.xml

Si las llamadas devuelven 200 pero las páginas siguen vacías, pide a Bob:

Las páginas renderizan pero no muestran datos. Compara los nombres de campo JSON
que devuelven los recursos REST con lo que esperan los componentes React, y reconcílialos.

/openapi/ui/ cargando no prueba que la API funcione

Liberty sirve Swagger UI en la raíz del servidor — carga aunque cada ruta /api devuelva 404. Confirma siempre con curl http://localhost:3000/api/dashboard o la URL directa del backend.
