Paso 7 — Importar el Store Associate Agent

El supervisor coordina el agente de disponibilidad y el agente RAG. Ambos deben estar importados antes de importar este YAML.

Desde la terminal de Lab2/confluent_agents, ejecuta:

orchestrate agents import --file Store_Associate_Agent.yaml
orchestrate agents list

Confirma que Store_Associate_Agent aparece junto a SKU_Availability_Agent y Substitute_Finder_Agent.

Desplegar y probar

  1. Abre Store_Associate_Agent en la UI de watsonx Orchestrate.
  2. Comprueba que sus colaboradores sean SKU_Availability_Agent y Substitute_Finder_Agent.
  3. Haz clic en Deploy y confirma.
  4. Prueba: "¿Tienes LAPTOP-MACBOOK-PRO-16 en Unicenter?"

Resultado esperado

Si el producto no tiene stock, el supervisor debe delegar la búsqueda de alternativas y responder con recomendaciones del catálogo. La respuesta no debe mencionar Kafka, MCP ni nombres internos de agentes.
