Flujo del laboratorio (para un buen output)

1 · Plan Plan Mode · PM — requisitos, backlog y criterios de aceptación. Aprueba el plan.
2 · Diseño Diseñador / Arquitecto — diagrama C4 o flujo en draw.io como contrato visual.
3 · Código Agent Mode · Developer — implementa solo lo del plan + diagrama.
4 · Test Agent Mode — pytest + bucle auto-fix hasta verde.
5 · Deploy DevOps — Dockerfile / CI y checklist de PR.
6 · Mantener Seguridad + Ops — secretos, vulns, monitoreo y changelog.

Regla de oro

No pases a la siguiente fase sin un artefacto aprobado: plan escrito → diagrama draw.io → diffs revisados → tests verdes → deploy documentado.
