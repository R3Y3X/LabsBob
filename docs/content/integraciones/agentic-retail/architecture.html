Component 1 — Confluent Cloud (Kafka)

The event backbone. Two Kafka topics drive the system:

  • inventory.transactions — raw inventory events (additions and sales) with fields: sku, branch, quantity, transaction_type
  • inventory.availability — derived topic auto-calculated by ksqlDB showing current available quantity per SKU per branch

Bob's role: Bob creates both topics using Python code from a single natural-language instruction.

Component 2 — ksqlDB (Stream Processing)

Continuously reads inventory.transactions, aggregates by sku and branch, and writes the latest available quantity to inventory.availability. This ensures agents always query current state, not snapshots.

Bob's role: Bob creates the ksqlDB cluster via Confluent CLI and writes the SQL stream + table definitions.

Component 3 — MCP Toolkit (sku-availability-checker)

A Python-based MCP tool exposing get_sku_availability(sku, branch) that queries the inventory.availability Kafka topic via ksqlDB. This is the bridge between Kafka and the AI agents.

Bob's role: Bob generates the MCP tool code, creates the .env configuration, and imports it into watsonx Orchestrate using the ADK CLI.

Component 4 — watsonx Orchestrate Agents (Multi-Agent)

Three specialized agents coordinate to answer store associate questions:

  • SKU Availability Agent — calls the MCP tool to check real-time stock
  • Substitute Finder Agent — performs semantic RAG over the product catalog to suggest alternatives
  • Store Associate Agent (supervisor) — routes requests to the specialist agents and combines their responses

Bob's role: Bob validates the YAML agent definitions and assists with the ADK import commands.

Component 5 — Enterprise Documents (RAG)

A product catalog Word document (product-catalog.docx) uploaded as a knowledge source (enterprise_documents) in watsonx Orchestrate. The Substitute Finder Agent performs semantic similarity search over this catalog to identify alternative products with matching attributes (category, processor class, memory tier, usage tier).
