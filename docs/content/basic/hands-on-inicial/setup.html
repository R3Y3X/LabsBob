Desarrollo Configuración Bob CLI

Configuración — Prepara tu workspace de Bob

Bob crea el directorio del proyecto, activa el entorno virtual de Python y confirma que el entorno está listo. Tú proporcionas la ruta y apruebas cada acción.

Guía paso a paso

Paso 1 — Abre el IDE de IBM Bob

Launch the Bob IDE from your applications folder or via the command line. Bob opens to the main workspace showing the chat panel on the right and the file explorer on the left. You will interact with Bob exclusively through natural-language prompts in the chat panel.

Resultado esperado

The Bob IDE loads with an empty chat panel, a mode selector (Plan / Agent / Ask), and an MCP server status indicator in the lower-left corner. All three modes should be available.

Paso 2 — Crea el directorio del proyecto

Tell Bob where to work. Bob will create the directory structure and a Python virtual environment. Make sure you are in Agent mode before sending this prompt.

Prompt de Bob

Hi Bob! For this project, create a directory ~/Documents/bob/workshop-hub
and use my Python virtual environment ~/.env/workshop-env.
If the virtual environment does not exist, create it for me.

Resultado esperado

Bob presents a task plan: (1) create directory, (2) create or locate venv, (3) create README. Click Approve. Bob then executes each action and shows a terminal confirmation for the directory creation.

Paso 3 — Valida el entorno

Ask Bob to activate the virtual environment and confirm everything is ready before moving to the first exercise.

Prompt de Bob

Activate the Python virtual environment and confirm the environment
is ready with the correct Python version and pip available.

Resultado esperado

Bob runs the activation command in the integrated terminal and reports back: Python 3.x.x · pip x.x · venv active at ~/.env/workshop-env. The task is marked complete.
