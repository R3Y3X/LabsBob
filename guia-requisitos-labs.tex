\section*{Instrucciones de uso}

Este documento lista \textbf{todos} los prerrequisitos de software, cuentas, accesos y configuraciones necesarios para participar en los laboratorios de IBM Bob. Está organizado en tres partes:

\begin{enumerate}[leftmargin=*, label=\arabic{enumi}.]
  \item \textbf{Requisitos universales} — herramientas necesarias para \emph{cualquier} lab.
  \item \textbf{Requisitos por laboratorio} — dependencias específicas de cada lab.
  \item \textbf{Guía de instalación paso a paso} — instrucciones por sistema operativo.
\end{enumerate}

\begin{warningbox}
  \textbf{Instala y valida todo el software con anticipación.} El día del lab no habrá tiempo para resolver problemas de entorno. Ejecuta los comandos de validación de cada sección y confirma que devuelven la versión esperada antes de la sesión.
\end{warningbox}

% ── IBM Bob IDE ──────────────────────────────────────────────
\subsection{IBM Bob IDE}

IBM Bob es el partner de IA que asiste en todo el ciclo de vida del software — desde planificación y diseño hasta implementación, pruebas y despliegue. Es el eje central de todos los laboratorios.

\begin{labbox}[ibmblue]{\faRobot\quad IBM Bob IDE — Instalación}
\begin{description}[leftmargin=3cm, style=nextline]
  \item[Descarga] \url{https://bob.ibm.com/download}
  \item[Versión] La más reciente disponible (siempre actualizar antes del lab)
  \item[Modos requeridos] Ask Mode, Plan Mode, Agent Mode
\end{description}
\vspace{6pt}
\textbf{Windows:} Seleccionar \emph{Bob IDE → Windows x64 (User)} \quad \texttt{.exe}\\
\textbf{macOS ARM} (M1/M2/M3/M4): Seleccionar \emph{Bob IDE → macOS → Mac ARM} \quad \texttt{.pkg}\\
\textbf{macOS Intel:} Seleccionar \emph{Bob IDE → macOS → Mac Intel} \quad \texttt{.pkg}\\
\textbf{Linux .deb} (Debian/Ubuntu): Seleccionar \emph{Bob IDE → Linux .deb amd64} \quad \texttt{.deb}\\
\textbf{Linux .rpm} (Fedora/RHEL): Seleccionar \emph{Bob IDE → Linux RPM x64} \quad \texttt{.rpm}
\vspace{6pt}\\
\textbf{Validación:} Abrir IBM Bob desde el menú Inicio o Launchpad. Si el editor carga correctamente, la instalación es válida. \checkmark
\end{labbox}

\begin{criticalbox}
  El Lab \textbf{IBM i RPG} requiere la suscripción \textbf{Premium Package for IBM i} habilitada en la cuenta de Bob, además de la instalación base. Confirmar con el facilitador antes de la sesión.
\end{criticalbox}

\section{Guía de Instalación por Sistema Operativo}
\label{sec:guia-instalacion}

Las instrucciones de esta sección cubren los prerrequisitos universales más las herramientas más frecuentes. Para herramientas específicas de labs avanzados (ADK, Confluent CLI, Maven, etc.), el facilitador proveerá instrucciones adicionales.

% ── WINDOWS ─────────────────────────────────────────────────
\subsection{Windows}
\label{sec:windows}

Los pasos asumen una PC con Windows sin herramientas de desarrollo previas. Ejecutar todos los comandos en \textbf{Git Bash} (instalado en el Paso 1), no en el símbolo del sistema de Windows.

\vspace{8pt}
\begin{labbox}[ibmdark]{\textbf{1} \quad Git Bash}
\textbf{Instalación:}
\begin{enumerate}[leftmargin=*, nosep]
  \item Descargar el instalador de 64 bits desde \url{https://git-scm.com/download/win}
  \item Ejecutar y completar el asistente con las opciones por defecto
\end{enumerate}
\vspace{4pt}
\textbf{Validación} (abrir Git Bash desde el menú Inicio):
\begin{center}
  \cmd{git -{}-version} \quad→\quad debe devolver \version{git version 2.x.x} \checkmark
\end{center}
\end{labbox}

\vspace{6pt}
\begin{labbox}[ibmdark]{\textbf{2} \quad Node.js LTS (incluye npm)}
\textbf{Instalación:}
\begin{enumerate}[leftmargin=*, nosep]
  \item Descargar el instalador LTS para Windows (.msi, 64 bits) desde \url{https://nodejs.org}
  \item Ejecutar el instalador con las opciones por defecto — \textbf{mantener activada la opción que agrega Node al PATH}
\end{enumerate}
\vspace{4pt}
\textbf{Validación} (en Git Bash):
\begin{center}
  \cmd{node -v} \quad→\quad \version{v24.x.x} \checkmark \qquad
  \cmd{npm -v} \quad→\quad \version{10.x.x} \checkmark
\end{center}
\textit{npm se instala automáticamente junto con Node.js.}
\end{labbox}

\vspace{6pt}
\begin{labbox}[ibmdark]{\textbf{3} \quad Python 3.12}
\begin{criticalbox}
  Debe ser \textbf{específicamente la versión 3.12.x}. Versiones anteriores o posteriores pueden causar incompatibilidades con librerías de los labs.
\end{criticalbox}
\vspace{6pt}
\textbf{Instalación:}
\begin{enumerate}[leftmargin=*, nosep]
  \item Descargar la versión más reciente \version{3.12.x} para Windows (64 bits) desde \url{https://www.python.org/downloads/windows/}
  \item Ejecutar el instalador y \textbf{marcar la opción «Add python.exe to PATH»} antes de continuar
  \item Completar con las opciones por defecto
\end{enumerate}
\vspace{4pt}
\textbf{Validación} (en Git Bash):
\begin{center}
  \cmd{python -{}-version} \quad→\quad \version{Python 3.12.x} \checkmark
\end{center}
\end{labbox}

\vspace{6pt}

% ── LINUX ────────────────────────────────────────────────────
\subsection{Linux (Debian/Ubuntu)}
\label{sec:linux}

Las instrucciones corresponden a distribuciones basadas en \textbf{Debian/Ubuntu}. Para Red Hat/Fedora, sustituir \cmd{apt} por \cmd{dnf} y el paquete \texttt{.deb} por \texttt{.rpm}.

\vspace{8pt}
\begin{labbox}[ibmdark]{\textbf{1} \quad Node.js LTS (incluye npm)}
\textbf{Instalación} (repositorio oficial NodeSource):
\begin{center}
\small
\cmd{curl -fsSL https://deb.nodesource.com/setup\_24.x | sudo -E bash -}\\
\cmd{sudo apt install -y nodejs}
\end{center}
\vspace{4pt}
\textbf{Validación:}
\begin{center}
  \cmd{node -v} \quad→\quad \version{v24.x.x} \checkmark \qquad
  \cmd{npm -v} \quad→\quad \version{10.x.x} \checkmark
\end{center}
\end{labbox}

\vspace{6pt}
\begin{labbox}[ibmdark]{\textbf{2} \quad Python 3.12}
\begin{criticalbox}
  Debe ser \textbf{específicamente la versión 3.12.x}. En Ubuntu 24.04 y Debian 12 está disponible en los repositorios oficiales.
\end{criticalbox}
\vspace{6pt}
\textbf{Instalación:}
\begin{center}
  \cmd{sudo apt update \&\& sudo apt install -y python3.12}
\end{center}
\textit{Verificar primero si ya está instalado: \cmd{python3 -{}-version}. Si devuelve \version{3.12.x}, no es necesario reinstalar.}
\vspace{4pt}\\
\textbf{Validación:}
\begin{center}
  \cmd{python3 -{}-version} \quad→\quad \version{Python 3.12.x} \checkmark
\end{center}
\end{labbox}

\vspace{6pt}
\begin{labbox}[ibmdark]{\textbf{3} \quad Google Chrome}
\textbf{Instalación:}
\begin{enumerate}[leftmargin=*, nosep]
  \item Descargar el paquete \texttt{.deb} desde \url{https://www.google.com/chrome/}
  \item Instalar:
\end{enumerate}
\begin{center}
  \cmd{sudo apt install -y ./google-chrome-stable\_current\_amd64.deb}
\end{center}
\vspace{4pt}
\textbf{Validación:} Abrir Chrome desde el menú de aplicaciones → ingresar \cmd{chrome://version} \checkmark
\end{labbox}

\vspace{6pt}
\begin{labbox}[ibmblue]{\textbf{4} \quad IBM Bob IDE}
\textbf{Instalación:}
\begin{enumerate}[leftmargin=*, nosep]
  \item Ingresar a \url{https://bob.ibm.com/download}
  \item Seleccionar:
    \begin{itemize}[nosep]
      \item \textbf{Debian/Ubuntu}: \emph{Bob IDE → Linux .deb amd64} \quad \texttt{.deb}
      \item \textbf{Fedora/RHEL}: \emph{Bob IDE → Linux RPM x64} \quad \texttt{.rpm}
    \end{itemize}
  \item Instalar desde la carpeta de descarga:
\end{enumerate}
\begin{center}
  \cmd{sudo apt install -y ./<archivo-descargado>.deb}
\end{center}
\vspace{4pt}
\textbf{Validación:} Abrir IBM Bob desde el menú de aplicaciones del sistema → si el editor carga, la instalación es correcta \checkmark
\end{labbox}
