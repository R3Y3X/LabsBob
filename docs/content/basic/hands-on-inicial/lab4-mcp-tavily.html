Lab 4 — MCP con Tavily

Conecta una herramienta externa al proyecto, mantén su secreto local y pide una respuesta verificable con fuentes.

1servidor MCP
1configuración local
3validaciones

Qué vas a lograr

  • Entender cuándo una conexión MCP debe ser global o de proyecto.
  • Configurar Tavily con una clave que no se versiona.
  • Confirmar que IBM Bob ve las herramientas y devuelve fuentes.

Qué es MCP y por qué el alcance importa

⇄Un protocolo para usar herramientas

MCP conecta IBM Bob con herramientas externas. En este lab, Tavily permite buscar información actual; IBM Bob decide cuándo usar la herramienta desde una conversación en Agent.

Global

Disponible en tus proyectos locales. Úsalo solo cuando la conexión y su acceso deban acompañarte fuera de este workshop.

Project · elegido aquí

Queda ligado a esta carpeta. Hace visible el contexto del workshop y reduce el alcance de la configuración.

La interfaz puede variar

Los nombres exactos de los paneles cambian entre versiones. Busca la sección MCP de Settings y selecciona la opción de proyecto antes de añadir o abrir la configuración.

Configura, verifica y usa Tavily

Paso 1 — Obtén una clave de Tavily

Navegador · Tavily

La clave autoriza al servidor de búsqueda; trátala como un secreto de desarrollo.

  1. Entra a tavily.com y crea o inicia sesión en tu cuenta.
  2. Crea una API key desde el dashboard y cópiala temporalmente.

Checkpoint

  • Tienes una clave disponible, pero todavía no la has pegado en un archivo versionado.

Paso 2 — Elige Project y abre la configuración

IBM Bob · Settings · MCP · Project

Asocia el servidor al workshop en vez de dejarlo disponible globalmente.

  1. Abre Settings y localiza MCP.
  2. Selecciona la configuración de Project; crea o abre el archivo de configuración del proyecto.
  3. Si la interfaz ofrece un editor JSON, úsalo para abrir el mismo archivo local.

Checkpoint

  • Estás configurando el alcance Project para la carpeta lab-4-mcp-tavily.

Paso 3 — Crea el archivo local con la clave

Archivo de configuración · .bob/mcp.json.example

La plantilla se comparte sin secretos; el archivo real solo vive en tu copia local.

  1. Duplica .bob/mcp.json.example como .bob/mcp.json.
  2. Reemplaza únicamente el placeholder por tu API key.
  3. Guarda el archivo local.

Archivo: .bob/mcp.json.example

{
  "mcpServers": {
    "tavily": {
      "command": "npx",
      "args": ["-y", "tavily-mcp@latest"],
      "env": {
        "TAVILY_API_KEY": "PEGA_TU_API_KEY_DE_TAVILY_AQUI"
      }
    }
  }
}

La clave no se sube a Git

El bundle ignora explícitamente .bob/mcp.json. Conserva el placeholder en .bob/mcp.json.example, no compartas el archivo real y revoca la clave si la expones.

Checkpoint

  • Existen la plantilla .bob/mcp.json.example y tu copia local .bob/mcp.json.
  • La clave real aparece solo en .bob/mcp.json.

Paso 4 — Confirma que el servidor está activo

IBM Bob · Settings · MCP · Project

IBM Bob debe iniciar el servidor y exponer sus herramientas antes de poder usarlas en el chat.

  1. Guarda la configuración y usa la acción de recarga si aparece.
  2. Busca tavily en la lista de servidores de proyecto.
  3. Comprueba que sus herramientas están visibles y no hay un error de inicio.

Checkpoint

  • El servidor tavily está activo y muestra herramientas disponibles.

Paso 5 — Solicita una búsqueda verificable

IBM Bob · Agent

Pide una respuesta que permita comprobar que Bob usó la herramienta y no solo conocimiento previo.

  1. Selecciona Agent.
  2. Envía el prompt y revisa la llamada de herramienta antes de aceptar cualquier acción adicional.

Pega en el chat de Bob

Busca en la web información actual sobre los precios de GitHub Copilot Enterprise.

Devuelve una respuesta breve con:
1. el precio por usuario/mes;
2. la fecha de la información o de cada fuente;
3. enlaces a las fuentes que usaste;
4. cualquier diferencia entre planes que afecte la comparación.

Checkpoint final

  • Viste que Agent puede usar Tavily o sus herramientas MCP.
  • La respuesta incluye fuentes enlazadas y fechas o una indicación clara de la actualidad de la información.
Si Tavily no aparece o no inicia
  • Confirma que el JSON es válido y que la clave quedó en .bob/mcp.json, no en la plantilla.
  • Revisa que Node.js 18 o posterior esté disponible y recarga la configuración MCP del proyecto.
  • Lee el mensaje de error del servidor antes de cambiar comandos o volver a crear la clave.
