FASE 3 — Generación de Tests (3 Batches)

Paso 3 — Batch 1: Tests de Modelos

FASE 3 — GENERACIÓN DE TESTS (un batch a la vez — muéstrame antes de crear)

BATCH 1 — Tests de modelos
  src/test/java/com/pharmacy/model/MedicineTest.java
  src/test/java/com/pharmacy/model/OrderTest.java
  src/test/java/com/pharmacy/model/PrescriptionTest.java

  Para cada modelo:
  - ConstructorTests: constructor vacío y constructor completo
  - GetterSetterTests: un test por campo
  - EdgeCaseTests: null values, strings vacíos, números negativos

Paso 4 — Batch 2: Tests de Repositorios

BATCH 2 — Tests de repositorios
  src/test/java/com/pharmacy/repository/MedicineRepositoryTest.java
  src/test/java/com/pharmacy/repository/PrescriptionRepositoryTest.java

  Para cada repo:
  - SingletonTests: getInstance() siempre devuelve la misma instancia
  - FindOperationsTests: findAll(), findById (existe/no existe/null), búsqueda por nombre
  - AddUpdateDeleteTests: add/update/delete con cleanup en @AfterEach

Paso 5 — Batch 3: Tests de Resources JAX-RS con Mockito

BATCH 3 — Tests de resources JAX-RS (usando @Mock de Mockito)
  src/test/java/com/pharmacy/api/MedicineResourceTest.java
  src/test/java/com/pharmacy/api/PrescriptionResourceTest.java

  Para cada resource: mockear el repositorio con @Mock y @ExtendWith(MockitoExtension.class)
  - GET all: 200 con lista, 200 con lista vacía
  - GET by id: 200 si existe, 404 si no existe
  - POST: 201 datos válidos, 400 medicine inexistente
  - PUT validate: 200 PENDING→VALIDATED, 400 ya VALIDATED, 404 no existe
