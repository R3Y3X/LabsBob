Desarrollo Parte 1 Bob CLI · Plan + Agent

Parte 1 — Tu primera tarea agéntica con Bob

Bob demuestra el flujo de tres modos — Plan → Agent → Ask — creando un script Python de hello world, ejecutándolo y documentándolo. Tú apruebas cada acción; Bob se encarga del resto.

Guía paso a paso

Paso 1 — Explora los modos de Bob (Ask Mode)

Start in Ask mode to learn about Bob's capabilities before giving it work. Ask mode does not execute anything — it only answers questions using its knowledge base and any connected MCP servers.

Prompt de Bob — Ask Mode

Explain what IBM Bob is and describe all available modes:
Plan mode, Agent mode, and Ask mode. What is each one used for?

Resultado esperado

Bob returns a structured explanation: Plan mode creates task lists and architecture designs without executing. Agent mode (also called Code mode) implements and runs code with your approval. Ask mode answers questions using documentation and context. No files are modified.

Paso 2 — Crea un archivo con Bob (Agent Mode)

Switch to Agent mode. Bob will create a Python file and run it. Watch the approval gate — Bob will show you exactly what it plans to write before touching the filesystem.

Prompt de Bob — Agent Mode

Create a file called hello-bob.py in the workshop-hub directory
that prints "Hello from Bob!" and today's date. Then run it.

Resultado esperado

Bob presents the file content for approval: a Python script importing datetime and printing the greeting + date. After you click Save, Bob runs the script in the terminal. You see Hello from Bob! followed by today's date in the output.

Paso 3 — Verifica el resumen de Bob

After completing a task, Bob always provides a summary of what it did. Use Ask mode to confirm the work and see how Bob tracks its own actions.

Prompt de Bob — Ask Mode

Summarize everything you did in this session.
List each file created, each command run, and the outcome.

Resultado esperado

Bob returns a structured task completion summary listing: directory created, virtual environment activated, hello-bob.py written and executed successfully. This is the same pattern used in all Bob tutorials — Bob always closes with a summary.

You have completed the Hands-on Inicial lab. You used all three Bob modes, understood the approval workflow, and ran your first agentic task. Proceed to the Software Development Lifecycle lab to see Bob drive a full development cycle.
