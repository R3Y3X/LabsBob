Objetivos de aprendizaje

  • Entender cuándo usar Plan Mode frente a Ask o Agent
  • Diseñar una solución con diagramas y alternativas, sin escribir código
  • Revisar un plan antes de implementarlo

Qué es Plan Mode

Plan Mode es el arquitecto: diseña la solución antes de implementarla. Crea diagramas, analiza requisitos y propone alternativas considerando seguridad y escalabilidad. No edita archivos.

Regla de oro

Cambia de modo según lo que necesites hacer. No uses un solo modo para todo. Puedes cambiar de modo a mitad de una tarea.

Ejercicio: diseñar un carrito de compras

Usa Plan Mode para diseñar la arquitectura de un carrito — sin escribir código. En el Lab 3 implementarás este plan con Agent Mode.

Paso 1 — Activa Plan Mode

  1. Abre el selector de modos → elige Plan
  2. Envía el prompt de diseño del carrito

Paso 2 — Envía el prompt de diseño

Necesito diseñar un sistema de carrito de compras para nuestra API de e-commerce.

Requisitos:
- Los usuarios deben poder agregar/eliminar productos
- Calcular el total con descuentos
- Persistir el carrito en la base de datos
- Validar stock antes de agregar

Por favor, diseña:
1. La estructura de datos del carrito
2. Los endpoints necesarios
3. El flujo de datos
4. Consideraciones de seguridad
5. Un diagrama de arquitectura

Qué debes ver

  • Diseño sin archivos creados aún
  • Diagramas Mermaid y alternativas
  • Un plan que puedas revisar y ajustar antes de pasar a Agent Mode

Lo que acabas de lograr

  • Diseñaste una solución con Plan Mode antes de tocar código
  • Revisaste el alcance, los riesgos y el diagrama sin que Bob escribiera archivos
