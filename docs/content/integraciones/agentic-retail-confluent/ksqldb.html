Streaming derivado ~15 min ksqlDB

Tópico derivado con ksqlDB

Calcula disponibilidad por SKU y sucursal a partir de las transacciones de inventario.

Crear el tópico derivado inventory.availability

Vas a crear un tópico derivado llamado inventory.availability que calcula cuántas unidades de cada producto hay en cada sucursal, procesando las transacciones del tópico anterior.

Un cluster de ksqlDB lee tópicos de Kafka, hace cálculos y escribe resultados en otros tópicos con SQL.

  1. Haz clic en ksqlDB en el menú izquierdo.
  2. Haz clic en el cluster ksqlDB que está corriendo.
  3. Haz clic en la pestaña Streams y Create in Editor.
  4. Copia y pega el siguiente código en el editor:
CREATE STREAM inventory_transactions (
     sku VARCHAR,
     branch VARCHAR,
     quantity INT
 ) WITH (
     KAFKA_TOPIC='inventory.transactions',
     KEY_FORMAT='KAFKA',
     VALUE_FORMAT='JSON'
 );
  1. Haz clic en Run Query.
  2. Crea la tabla inventory_availability agrupando por SKU y sucursal, y luego Run Query. Esto:
    • Agrupa las transacciones por SKU y sucursal.
    • Suma cantidades (positivas = ingreso, negativas = venta).
    • Escribe el resultado en inventory.availability.
    • Se actualiza cuando llegan transacciones nuevas.
CREATE TABLE inventory_availability WITH (
  KAFKA_TOPIC='inventory.availability',
  KEY_FORMAT='JSON',
  VALUE_FORMAT='JSON',
  PARTITIONS=1
) AS
SELECT
  sku,
  branch,
  SUM(quantity) AS available_quantity
FROM inventory_transactions
GROUP BY sku, branch
EMIT CHANGES;
