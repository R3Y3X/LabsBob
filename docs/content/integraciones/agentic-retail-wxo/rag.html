Importa el segundo agente y conéctalo al catálogo de productos.

Paso 5 — Importar el Substitute Finder Agent

El Substitute Finder Agent no consulta inventario en tiempo real: razona sobre el catálogo para encontrar alternativas cuando un SKU no está disponible.

Desde la misma terminal donde activaste el ambiente y después de importar el agente de disponibilidad, ejecuta:

orchestrate agents import --file Substitute_Finder_Agent.yaml
orchestrate agents list

Confirma que aparecen ambos agentes antes de continuar con el supervisor.

Paso 6 — Crear la base de conocimiento

El archivo product-catalog.docx es el catálogo interno que el agente usa como fuente para recomendar sustitutos.

  1. Abre Substitute_Finder_Agent en la UI de watsonx Orchestrate.
  2. Entra a Knowledge y haz clic en Add source.
  3. Crea una base de conocimiento nueva y usa Upload files.
  4. Sube product-catalog.docx, nómbrala enterprise_documents y espera a que termine la indexación.
  5. Haz clic en Deploy y confirma que el agente quede disponible.

Probar el agente RAG

"LAPTOP-DELL-XPS-15 no está disponible. Sugiere una laptop similar usando el catálogo de productos."

La respuesta debe basarse en atributos del documento y no inventar disponibilidad.
