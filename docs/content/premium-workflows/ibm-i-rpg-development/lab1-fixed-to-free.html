Laboratorio 1 — Conversión de RPG de formato fijo a libre

Convierte lógica RPG de formato fijo a formato libre con procedimientos y constantes nombradas.

Objetivo Dcl-Proc
~20 minutos
3–6 BobCoins estimados
Premium acceso requerido

Introducción

Aprenda a usar IBM Bob para analizar código RPG heredado y convertirlo del formato fijo al formato libre moderno.

lo que construirás

Convierta una subrutina RPG de formato fijo a formato libre.

Caso de uso: convertir la lógica de carga de subarchivos

Convertiremos la subrutina s01lod (Cargar subarchivo) del formato fijo al formato libre.

Paso 1: Pídale a Bob que le explique el código

Pregunta para Bob: 

        @SAMCO/QRPGLESRC/ART200-Work_with_article.PGM.SQLRPGLE

Explique qué hace la subrutina s01lod (líneas 102-118).
Centrarse en:
1. Qué datos lee
2. Cómo carga el subarchivo
3. Qué hace el bucle
Mantenlo simple y conciso.

que buscar

  • Bob explica que se lee en el archivo ARTICLE2.
  • Carga 14 registros en un subarchivo.
  • Utiliza un contador y %EOF para controlar el bucle.

Paso 2: Pídele a Bob que convierta al formato libre

Pregunta para Bob: 

        Convierta la subrutina s01lod (líneas 102-118) del formato fijo al formato libre.

Requisitos:
- Utilice Dcl-Proc en lugar de BEGSR/ENDSR
- Mantén la misma lógica.
- Añadir comentarios explicando cada sección.
- Utilice la sintaxis moderna de RPG IV.

Muéstrame el código convertido.

La respuesta de Bob (ilustrativa)

          // Cargar procedimiento de subarchivo
Dcl-Proc CargarSubfile;

  // Restaurar la posición de la última lectura
  RestaurarPosición();

  // Inicializar subarchivo
  RRb01 = RRn01 + 1;
  optar01 = 0;
  contar = 0;

  // Lee y carga hasta 14 registros
  Leer ARTÍCULO 2;
  DoW no %Eof(ARTÍCULO2) Y cuenta <14;
    RRN01 += 1;
    contar += 1;
    Escribe SFL01;
    Leer ARTÍCULO 2;
  FinHacer;

  // Establecer indicador de fin de archivo
  sflend = %Eof(ARTÍCULO1);
  paso01 = dsp;

  //Guardar posición actual
  GuardarPosición();

Fin-Proc;

Paso 3: Pregúntale a Bob sobre las mejoras

Pregunta para Bob: 

        ¿Qué mejoras se pueden hacer a este código convertido?
Sugiera 2-3 mejoras simples para mejorar la legibilidad o el mantenimiento.

Sugerencias esperadas

  1. Extraiga el número mágico 14 a una constante.
  2. Utilice nombres de variables más descriptivos.
  3. Agregar manejo de errores.

Si Bob no te muestra automáticamente una nueva implementación con las actualizaciones, puedes pedírselo directamente.

Criterios de éxito

Ha completado con éxito esta práctica de laboratorio cuando:

  • Bob explicó el código de formato fijo original
  • Código convertido a formato libre con Dcl-Proc
  • Número mágico reemplazado por una constante con nombre
  • Entiendes las diferencias antes/después

Conclusiones clave

  1. Bob puede explicar : use Bob para comprender el código heredado rápidamente.
  2. El formato libre es más claro : la sintaxis moderna es más legible.
  3. Constantes con nombre : reemplaza los números mágicos para facilitar el mantenimiento.
  4. Cambios incrementales : convierte una subrutina a la vez.

Pasos adicionales

  • Intente convertir otra subrutina ( s01chk o s01act ).
