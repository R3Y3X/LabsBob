FASE 2 — Cambios

Paso 2 — Aplicar los 6 cambios de migración

FASE 2 — CAMBIOS (uno a la vez — explica, espera "ok", luego aplica)

Cambio 1 — Compilador Java 21 en pom.xml (APROBAR)
  maven.compiler.source/target: 1.8 → 21, añadir release=21
  maven-compiler-plugin → 3.15.0, maven-war-plugin → 3.5.1

Cambio 2 — Struts 6.4.0 en pom.xml (APROBAR)
  struts2.version: 2.5.30 → 6.4.0
  Añadir exclusiones de javassist y dependencyManagement forzando javassist 3.29.2-GA

Cambio 3 — Dependencias javax → jakarta en pom.xml (APROBAR)
  javax.servlet-api → jakarta.servlet-api:6.0.0
  javax.servlet.jsp-api → jakarta.servlet.jsp-api:3.0.0
  javax.servlet:jstl → org.glassfish.web:jakarta.servlet.jsp.jstl:3.0.1

Cambio 4 — server.xml: features Jakarta EE 10 (APROBAR)
  Reemplazar servlet-3.1, jsp-2.3, jdbc-4.1 con webProfile-10.0 y mpMetrics-5.1
  ⚠️ Usar webProfile-10.0, NO jakartaee-10.0 completo.

Cambio 5 — imports javax → jakarta en código Java (APROBAR)
  javax.servlet.* → jakarta.servlet.*
  javax.servlet.jsp.* → jakarta.servlet.jsp.*

Cambio 6 — taglib URIs en JSPs (APROBAR)
  http://java.sun.com/jsp/jstl/core → https://jakarta.ee/xml/ns/jakartaee
