Fase 6 — Mantener: seguridad y operaciones

Cierra el ciclo: escaneo de secretos y vulnerabilidades, documentación operativa y señales de monitoreo. Bob actúa como Seguridad + Ops.

Paso a paso

Paso 1 — Revisión de seguridad

Prompt — Ask Mode

Audita el proyecto de la API de todos en busca de:
1. Secretos hardcodeados o logs sensibles
2. Validación de inputs insuficiente
3. Dependencias con riesgos conocidos
4. Recomendaciones priorizadas (crítica / alta / media)

No modifiques archivos; solo informe.

Paso 2 — Documentación operativa

Prompt — Agent Mode

Actualiza o crea:
1. README con cómo correr local, tests y Docker
2. CHANGELOG con las fases del lab
3. Sección "Operación" con métricas sugeridas (latencia, errores 4xx/5xx)
   inspirada en herramientas tipo Sentry / Datadog / Grafana

Alinea nombres con el diagrama draw.io.
Muestra diffs antes de escribir.

Output esperado

Informe de seguridad + docs de operación. El ciclo queda listo para volver a Plan si surge un nuevo requisito.

Paso 3 — Cierre del ciclo

  • Plan aprobado
  • Diagrama draw.io versionado
  • Código + tests verdes
  • Dockerfile / CI
  • Auditoría y docs de mantenimiento

¡Ciclo completo!

Has recorrido Plan → Diseño → Código → Test → Deploy → Mantener con Bob. Vuelve al Inicio o repite el flujo con otro alcance.
