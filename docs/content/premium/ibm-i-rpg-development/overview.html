Del RPG al futuro: moderniza IBM i

SAMCO es un sistema de gestión de pedidos con pantalla verde y código RPG de más de 20 años. En este workshop usas IBM Bob sobre el código fuente local: descubrimiento, Fixed-to-Free, UI React + Carbon y RLA a SQL.

4 laboratorios
~90 minutos
12–28 BobCoins estimados

Qué vamos a modernizar

Trabajarás con el árbol fuente SAMCO (RPG, DDS, SQL) abierto en Bob: un sistema de pedidos con pantalla verde y código de más de 20 años. Cada lab es independiente; el orden recomendado construye habilidades de forma progresiva.

Estado inicial (legacy)

Pantalla verde 5250 con patrón panel-step
RPG formato fijo (columnar) y subrutinas
Acceso a datos con RLA (CHAIN, SETLL, READ)
Sin interfaz web moderna

Estado objetivo (modernizado)

Reglas de negocio y flujos claros con Ask Mode
RPG free-format con Dcl-Proc y constantes nombradas
SQL embebido con SELECT y JOIN
UI React + TypeScript + Carbon Design System

También puedes empezar por el Lab 2 si prefieres ver primero la interfaz web.

Cómo trabaja Bob en cada lab

Usas Ask Mode para descubrir y explicar, y Agent/Code Mode cuando hay que crear o convertir código. Bob muestra el cambio y tú apruebas antes de aplicar.

Descubrimiento

Bob lee el código SAMCO y explica reglas de negocio, flujos y patrones sin modificar archivos.

Modernización

Conviertes RPG Fixed-to-Free y RLA a SQL con prompts; revisas el resultado antes de continuar.

UI moderna

En el Lab 2 construyes una app React + Carbon con datos de muestra y la validas en el navegador.
