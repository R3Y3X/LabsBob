Modernización de aplicaciones Java legacy

Moderniza Java a la velocidad del negocio

Simple Pharmacy Management System es una aplicación web de operaciones farmacéuticas (recetas, pedidos, inventario de medicamentos, dashboards). Parte de Traditional WebSphere + Java 8 + Struts y se moderniza progresivamente hacia Liberty + Java 21 + React, con tests y remediación de CVEs.

Cómo encajan los labs

Los Labs 1–3 forman el recorrido principal y secuencial. El Lab 4, el Lab 4 alternativo y el Lab 5 pueden realizarse después en el orden que necesites. En esta variante Bob ejecuta los workflows nativos; revisa cada análisis, plan y aprobación antes de continuar.

Qué cambia al tener Premium

En lugar de reproducir cada fase con prompts, abre Workflows ▶ y elige el flujo: Java Modernization (subtipos Liberty Replatforming, Java Upgrade y UI Modernization), Java Unit Testing y Java Vulnerabilities Detection. El Lab Alt-4 (TDD) no tiene workflow: se hace en Agent Mode.

2. Java + Maven

El Lab 1 usa Java 8; desde el Lab 2 se usa Java 21. Instala ambas versiones y Maven ahora, y reinicia Bob tras instalar Maven para que detecte el PATH actualizado.

macOS

Ver comandos con SDKMAN!

Instala SDKMAN!, Java 8, Java 21 y Maven. Ejecuta cada comando en orden:

curl -s "https://get.sdkman.io" | bash
source "$HOME/.sdkman/bin/sdkman-init.sh"
sdk install java 8.0.492-zulu
sdk default java 8.0.492-zulu
sdk install java 21.0.7-zulu
sdk install maven

Linux

Ver comandos con SDKMAN!

Instala SDKMAN!, Java 8, Java 21 y Maven. Ejecuta cada comando en orden:

curl -s "https://get.sdkman.io" | bash
source "$HOME/.sdkman/bin/sdkman-init.sh"
sdk install java 8.0.492-zulu
sdk default java 8.0.492-zulu
sdk install java 21.0.7-zulu
sdk install maven

Windows

Ver comandos en PowerShell
winget install EclipseAdoptium.Temurin.8.JDK
winget install EclipseAdoptium.Temurin.21.JDK
winget install Apache.Maven

También puedes usar SDKMAN! desde Git Bash o WSL.

Comprueba el entorno antes de abrir el Lab 1

java -version
mvn --version

Para el Lab 1, ambos comandos deben informar Java 8. Cambia a Java 21 antes de empezar el Lab 2.

3. Node.js LTS — solo Lab 3

Instala Node.js 20 o 22 LTS desde nodejs.org o con winget install OpenJS.NodeJS.LTS en Windows.

Libera los puertos entre labs

Detén cualquier servidor Liberty antes de continuar. Si un puerto queda ocupado, el siguiente lab puede ejecutar una instancia anterior.

lsof -ti:9080,9081,9443 | xargs kill -9
