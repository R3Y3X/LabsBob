Cheatsheet - Techzone Confluent VM

Guía rápida de comandos para interactuar con cada componente de la plataforma Confluent desplegada en tu VM de TechZone.

Todos los ejemplos asumen que configuraste estas variables en tu terminal:

Continúa desde el bundle personalizado del track de Confluent y usa siempre el WORKSHOP_ID de tu mesa y número.

HOST=<tu IP pública o hostname>      # ej. 163.66.89.122
ADMIN_PW=<password de admin>         # en /var/lib/confluent-access/credentials.json
KAFKA_PW=<password de kafka-admin>   # en el mismo json, bajo .kafka.password

Para obtener ambos passwords de una sola vez ejecutando desde tu máquina local:

ssh -i cflt-vsi-key.pem root@$HOST 'sudo jq "{admin: .password, kafka: .kafka.password}" /var/lib/confluent-access/credentials.json'

1. Schema Registry

Listar todos los subjects (esquemas) registrados:

curl -sk -u admin:$ADMIN_PW https://$HOST/sr/subjects

Ver la última versión de un schema específico (ej. inventory.transactions-value):

curl -sk -u admin:$ADMIN_PW https://$HOST/sr/subjects/inventory.transactions-value/versions/latest

2. ksqlDB

Ejecutar una consulta SQL (ej. listar streams):

curl -sk -u admin:$ADMIN_PW -X POST -H "Content-Type: application/vnd.ksql.v1+json" \
     https://$HOST/ksqldb/ksql \
     -d '{"ksql":"SHOW STREAMS;","streamsProperties":{}}'

Reemplaza SHOW STREAMS; con SHOW TABLES;, SHOW TOPICS; o cualquier query válida.

3. Kafka Connect

Listar los conectores desplegados actualmente:

curl -sk -u admin:$ADMIN_PW https://$HOST/connect/connectors

Listar datagens y conectores de prueba disponibles en el clúster:

ssh -i cflt-vsi-key.pem root@$HOST 'bash /opt/confluent-installer/scripts/deploy-datagen-connector.sh list'

4. CMF (Apache Flink)

Listar Flink environments configurados:

curl -sk -u admin:$ADMIN_PW https://$HOST/cmf/api/v1/environments

Ver los compute pools (recursos asignados a Flink):

curl -sk -u admin:$ADMIN_PW https://$HOST/cmf/api/v1/environments/flink-env/compute-pools

5. Kafka Brokers (Native Protocol)

Para usar librerías nativas como Python confluent_kafka o herramientas como kcat, necesitas copiar el certificado root de la VM a tu equipo:

scp -i cflt-vsi-key.pem root@$HOST:/var/lib/confluent-access/kafka-ca.crt ./kafka-ca.crt

Configuración del cliente (Python / kcat)

Archivo de configuración · cliente Kafka

bootstrap.servers=<host>:9094,<host>:9095,<host>:9096
security.protocol=SASL_SSL
sasl.mechanism=PLAIN
sasl.jaas.config=org.apache.kafka.common.security.plain.PlainLoginModule required username="kafka-admin" password="<kafka pw>";
ssl.endpoint.identification.algorithm=https
ssl.ca.location=./kafka-ca.crt

Usar kcat

Listar tópicos y brokers con kcat:

kcat -L \
  -b $HOST:9094,$HOST:9095,$HOST:9096 \
  -X security.protocol=SASL_SSL \
  -X sasl.mechanism=PLAIN \
  -X sasl.username=kafka-admin \
  -X sasl.password=$KAFKA_PW \
  -X ssl.ca.location=./kafka-ca.crt
