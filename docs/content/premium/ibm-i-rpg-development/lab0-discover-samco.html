Contexto del lab

Antes de escribir una sola línea de código, necesitas entender con qué estás trabajando. En este lab usarás IBM Bob para explorar SAMCO: su propósito, reglas de negocio y cómo encaja todo.

No escribirás código. Harás una serie de preguntas a Bob sobre los archivos del proyecto y Bob te lo explicará en lenguaje claro.

Paso obligatorio — antes de cualquier prompt

Punto de partida

Descarga y descomprime el bundle SAMCO. Abre como raíz en IBM Bob la carpeta del workshop que contiene SAMCO/; las referencias @SAMCO/... de este lab dependen de ese workspace.

  • La carpeta raíz está abierta mediante File → Open Folder.
  • El explorador muestra la carpeta SAMCO/.
  • El chat de Bob está en Ask Mode; este lab no modifica archivos.

Paso 0 — Activa Ask Mode

Para este lab Bob solo necesita leer y explicar la aplicación, no hacer cambios. Cambia a Ask Mode antes de empezar.
