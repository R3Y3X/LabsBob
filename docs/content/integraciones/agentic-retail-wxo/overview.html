Sistema multiagente para retail

En este laboratorio vas a construir un sistema multiagente para asistir a una tienda retail. El sistema combina eventos de inventario en tiempo real, provistos por Confluent, con agentes de IA creados en IBM watsonx Orchestrate.

La consulta de inventario se realiza mediante un MCP remoto compartido en una VM. Orchestrate consume el toolkit ya registrado y los agentes se importan desde archivos YAML.

No vas a escribir comandos

Todo el trabajo de terminal — instalar la CLI, activar el ambiente, importar los agentes — lo ejecuta IBM Bob en Agent Mode. Tú copias prompts y, al final de cada fase, entras a tu instancia de watsonx Orchestrate a probar el agente que acabas de importar.

Qué vas a construir

  1. SKU Availability Agent: consulta stock en tiempo real usando get_sku_availability.
  2. Substitute Finder Agent: usa RAG sobre el catálogo de productos para recomendar sustitutos.
  3. Store Associate Agent: coordina disponibilidad y sustitutos para un asociado de tienda.
  4. Customer Shopping Assistant: recomienda productos y verifica disponibilidad para el cliente final.

El toolkit no se importa desde tu laptop

El facilitador registra el MCP compartido una sola vez. Si orchestrate toolkits list no muestra el toolkit, detente y avisa al facilitador; no ejecutes un registro alternativo con credenciales locales.

Descarga los materiales del workshop

Archivos importantes del Lab 2

  • Lab2/confluent_agents/*.yaml — especificaciones de los cuatro agentes.
  • Lab2/confluent_agents/workshop-config.env.example — plantilla con la URL de la instancia, el endpoint del MCP y el nombre del toolkit. La copias a workshop-config.env, que queda solo en tu equipo.
  • Lab2/confluent_agents/register_shared_toolkit.sh — script para uso exclusivo del facilitador.
  • Lab2/confluent_agents/product-catalog.docx — fuente de conocimiento del agente RAG.

Orden del recorrido

  1. Disponibilidad MCP — Bob prepara la CLI, activa la instancia, verifica el toolkit compartido e importa el primer agente. Lo pruebas en Orchestrate.
  2. Sustitutos RAG — importas el agente de sustitutos, cargas el catálogo como base de conocimiento y compruebas que cite el documento.
  3. Supervisor — importas el coordinador de tienda y verificas que delegue en sus dos colaboradores.
  4. Asistente cliente — importas el agente de cara al cliente, lo pruebas y copias el snippet embebible.

Cada fase termina igual: entras a tu instancia de watsonx Orchestrate, pruebas el agente que acabas de importar y repasas los criterios de éxito antes de seguir.
