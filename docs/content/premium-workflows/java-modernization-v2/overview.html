Java y Maven

El Lab 1 arranca en Java 8. Desde el Lab 2 el workflow pide Semeru 21, así que instala las dos versiones y Maven ahora. Después de instalar Maven, cierra y vuelve a abrir Bob para que tome el PATH nuevo.

macOS y Linux

SDKMAN! instala y cambia entre versiones de Java. Copia el bloque entero y ejecútalo en orden:

curl -s "https://get.sdkman.io" | bash
source "$HOME/.sdkman/bin/sdkman-init.sh"
sdk install java 8.0.504+1-zulu
sdk default java 8.0.504+1-zulu
sdk install java 21.0.12-sem
sdk install maven

Apple Silicon

Temurin no tiene Java 8 para arm64. Por eso usamos Zulu, que sí corre en Intel y en Macs de la serie M.

Windows

Elige una opción y quédate en ella todo el workshop. No mezcles PowerShell nativo con WSL.

winget install --id Azul.Zulu.8.JDK --exact
winget install --id IBM.Semeru.21.JDK --exact
winget install --id Apache.Maven --exact

Cierra y vuelve a abrir PowerShell y Bob. Para el Lab 1, JAVA_HOME debe apuntar a Zulu 8; desde el Lab 2, a Semeru 21.

Opción B — WSL 2 + SDKMAN!

En PowerShell como administrador:

wsl --install

Abre Ubuntu/WSL — no PowerShell — e instala las herramientas de base y el mismo stack que en macOS/Linux:

sudo apt update && sudo apt install -y curl zip unzip lsof
curl -s "https://get.sdkman.io" | bash
source "$HOME/.sdkman/bin/sdkman-init.sh"
sdk install java 8.0.504+1-zulu
sdk default java 8.0.504+1-zulu
sdk install java 21.0.12-sem
sdk install maven

Deja el workshop en el sistema de archivos de WSL y abre Bob en el contexto WSL. Todos los comandos sdk, java, mvn y npm salen de esa terminal.

Comprueba el entorno antes del Lab 1

java -version
mvn --version

Los dos deben reportar Java 8 (1.8). Cambia a Java 21 antes de empezar el Lab 2. Maven lo instalas tú; si falta el JDK, Bob puede instalarlo con SDKMAN!, pero en un taller cronometrado conviene tenerlo listo.

Node.js — solo Lab 3

El frontend React del Lab 3 necesita Node.js 22. En macOS, Linux o WSL:

curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.40.6/install.sh | bash
source "$HOME/.nvm/nvm.sh"
nvm install 22
nvm use 22

En Windows nativo (PowerShell), instala Node 22 y vuelve a abrir Bob:

winget install --id OpenJS.NodeJS.22 --exact

Libera los puertos entre labs

Si dejas Liberty en marcha, el lab siguiente puede engancharse a esa instancia. El Lab 1 usa el puerto 9080; los Labs 2–5 usan 9081 (y a veces 9443).

macOS, Linux o WSL:

lsof -ti:9080,9081,9443 | xargs kill -9

PowerShell de Windows:

Get-NetTCPConnection -LocalPort 9080,9081,9443 -ErrorAction SilentlyContinue |
  Select-Object -ExpandProperty OwningProcess -Unique |
  ForEach-Object { Stop-Process -Id $_ -Force }
