Integración ~30 min Supervisor & Asistente

Integración — Supervisor y Asistente de Compra

Configura los agentes supervisores para empleados de tienda y el asistente embebible para clientes finales.

Paso 3 — Crear el agente supervisor para asociados de tienda

En este paso vas a crear el Store Associate Agent. Este agente funciona como supervisor: recibe una consulta de un asociado de tienda, delega la verificación de stock al agente de disponibilidad y, si hace falta, delega la búsqueda de alternativas al agente de sustitutos.

3.1. Importar y desplegar el agente supervisor

Desde la terminal en Lab2, ejecutá:

orchestrate agents import -f confluent_agents/Store_Associate_Agent.yaml

Luego, en la UI de watsonx Orchestrate, abrí el agente Store_Associate_Agent y hacé clic en Deploy.

Probar el agente supervisor

Probá una consulta de disponibilidad y sustitutos en la interfaz del agente:

"¿Tenés LAPTOP-MACBOOK-PRO-16 en Unicenter?"

Si el producto no está disponible según el inventario actual, el agente delega la tarea y recomienda alternativas del catálogo.

Paso 4 — Crear el asistente de compra para el cliente final

En este paso vas a crear el Customer Shopping Assistant, un agente orientado al cliente final. A diferencia del agente para asociados de tienda, este asistente no parte necesariamente de un SKU: interpreta necesidades expresadas en lenguaje natural y las traduce en recomendaciones concretas.

4.1. Importar el asistente

Desde Lab2, ejecutá:

orchestrate agents import -f confluent_agents/Customer_Shopping_Assistant.yaml

4.2. Vincular la base de conocimiento y herramienta

  1. Abrí el agente Customer_Shopping_Assistant.
  2. En el menú lateral, ingresá a Knowledge, hacé clic en Add source y seleccioná la fuente existente enterprise_documents.
  3. En el menú lateral, ingresá a Toolset, y asegurate de que la herramienta sku-availability-checker:get_sku_availability esté vinculada. Si no lo está, agregala.
  4. Volvé a la vista principal del agente y hacé clic en Deploy.

4.3. Obtener el snippet para embeber el asistente

Este paso prepara el material necesario para el Lab 3, donde el asistente se integrará en una página web local (Voltia Storefront).

  1. En el menú lateral del agente, ingresá a Channels.
  2. Seleccioná Embedded agent.
  3. Abrí la pestaña Live.
  4. En Embed on your website, copiá el snippet de código HTML/JS.
  5. Guardalo de forma segura, lo utilizarás en el próximo laboratorio.
