Antes de comenzar

Descomprime el zip. En IBM Bob abre la carpeta de cada lab con File → Open Folder — el IDE apuntará automáticamente al directorio correcto. Para el Lab 1 ejecuta npm install en la terminal integrada. Necesitarás Node.js 18+ y, para el Lab 4 (MCP), una API key gratuita de Tavily.

Gobernado

Desarrollo seguro por diseño

Toda acción sobre archivos, comandos y herramientas externas requiere aprobación explícita. Bob documenta cada cambio y ofrece rollback granular por tarea, turno o llamada.

Personalizable

Especializado para tu organización

Skills, MCP servers y modos personalizados en YAML configuran a Bob como experto en tus estándares: PCI-DSS, HIPAA, arquitecturas de IBM Cloud o cualquier dominio propio.

3× más rápido

Ejecución paralela de herramientas

Múltiples herramientas corren simultáneamente. Tareas que tomaban 30 segundos ahora duran menos de 10. Subagentes con contexto aislado procesan subtareas sin inflar el agente principal.

Los 3 modos especializados

Ask Mode

El Consultor — Solo lectura

Analiza código, explica arquitecturas, genera documentación y detecta problemas sin modificar ningún archivo. Lectura auto-aprobada con 270k tokens de contexto.

  • Arquitectura y diagramas Mermaid
  • Auditoría de seguridad (read-only)
  • README y documentación técnica

Plan Mode

El Arquitecto — Diseño primero

Propone arquitecturas, evalúa alternativas, genera diagramas Mermaid y valida requisitos antes de escribir una sola línea de código. Seguridad y escalabilidad en el diseño, no al final.

  • Diseño arquitectónico guiado
  • Análisis de edge cases y riesgos
  • Sin edición de archivos

Agent Mode

El Implementador — Acción completa

Escribe, refactoriza y ejecuta código. Accede a MCP, browser y skills. Delega a subagentes, corre tareas en paralelo y en segundo plano. Edición de comandos antes de ejecutar.

  • MCP + Browser + Skills nativo
  • Subagentes + tareas paralelas
  • Aprobación requerida para escrituras

Agenda de los modos (~50 min)

00–08 min Lab 1 — Ask Mode: análisis de arquitectura y documentación
08–28 min Lab 2 — Plan y Agent: diseñar, implementar y revisar el carrito
28–40 min Lab 3 — Modo personalizado: crea un Product Manager
