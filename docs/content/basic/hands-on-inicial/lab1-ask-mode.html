¿Qué es Ask Mode?

Ask Mode — El Consultor

Modo especializado en análisis y comprensión de código. No modifica ningún archivo.

  • Analiza múltiples archivos simultáneamente
  • Mantiene 270 000 tokens de contexto en la conversación
  • Genera visualizaciones y diagramas (Mermaid)
  • Las lecturas se aprueban automáticamente — solo escrituras requieren confirmación
  • Crea documentación estructurada

Casos de Uso de Ask Mode

  • Onboarding de nuevos devs: "Explícame cómo funciona el sistema de autenticación"
  • Code Review: "¿Qué patrones de diseño se usan en este módulo?"
  • Refactoring: "¿Dónde se usa esta función y cuál es su impacto?"
  • Documentación: "Genera un README para este microservicio"

Ejercicio Práctico

Paso 1 — Preparar el Proyecto de Ejemplo

Vamos a analizar una aplicación de e-commerce simple incluida en este laboratorio.

# Verifica que estás en el directorio correcto
cd lab-1-ask-mode
ls -la

Deberías ver la siguiente estructura:

├── README.md
├── src/
│   ├── app.js
│   ├── models/
│   │   ├── User.js
│   │   └── Product.js
│   ├── controllers/
│   │   ├── authController.js
│   │   └── productController.js
│   └── routes/
│       └── api.js
└── package.json

Paso 2 — Activar Ask Mode

Cambia el modo de Bob a Ask antes de analizar el proyecto.

  1. Haz clic en el selector de modos (parte superior del chat)
  2. Selecciona Ask
  3. Verifica en la barra de estado: debe aparecer Ask activo

Paso 3 — Análisis de Arquitectura

Abre el chat (Cmd/Ctrl + Shift + I) y pega este prompt:

Analiza la arquitectura de este proyecto de e-commerce.
Explícame:
1. ¿Qué patrón arquitectónico se está usando?
2. ¿Cuáles son los componentes principales?
3. ¿Cómo fluyen los datos entre capas?

Qué debes ver

  • Lecturas auto-aprobadas de archivos
  • Identificación del patrón MVC
  • Relaciones entre capas y sugerencias

Paso 4 — Análisis Profundo de Código

Profundiza en un componente específico:

Analiza el archivo authController.js y explícame:
1. ¿Qué vulnerabilidades de seguridad tiene?
2. ¿Qué mejores prácticas no se están siguiendo?
3. ¿Cómo podría mejorarse el manejo de errores?

Tip Pro

IBM Bob puede leer archivos completos en un solo paso. Si necesitas más contexto puedes decir: "Lee también User.js y api.js" — con 270k tokens de contexto, Bob mantiene todo en mente.

Paso 5 — Generar Documentación Automática

Pide un README profesional. Ask Mode no escribe archivos hasta que lo apruebes (o puedes copiar el resultado).

Genera un README.md completo para este proyecto que incluya:
1. Descripción del proyecto
2. Arquitectura y componentes
3. Instrucciones de instalación
4. Endpoints de la API con ejemplos
5. Diagrama de flujo de autenticación

Paso 6 — Preguntas de Seguimiento (Contexto)

IBM Bob recuerda toda la conversación. Aprovecha el contexto acumulado con preguntas de seguimiento:

¿Dónde se validan los datos de entrada del usuario?
¿Qué pasa si un usuario intenta acceder a un producto que no existe?
¿Cómo se manejan las sesiones de usuario?

Desafíos Opcionales

Desafío 1 — Análisis de Dependencias

Analiza el package.json y dime:
1. ¿Qué dependencias tienen vulnerabilidades conocidas?
2. ¿Hay dependencias obsoletas?
3. ¿Qué alternativas más modernas existen?

Desafío 2 — Diagrama de Secuencia

Genera un diagrama de secuencia en Mermaid que muestre
el flujo completo de una petición de login desde que
llega al servidor hasta que se devuelve el token JWT.
