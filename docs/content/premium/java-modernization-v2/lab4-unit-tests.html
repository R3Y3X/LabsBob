Cómo funciona (Agent Mode por fases)

En lugar del workflow Java Unit Testing, este lab usa prompts por fases en Agent Mode que reproducen el mismo flujo de nueve pasos del workshop:

  1. Análisis del proyecto — estructura, build tool, infraestructura de tests existente
  2. Generación de estrategia — produce UNITTEST.md con patrones de nombres, mocking y alcance
  3. Instalación de JaCoCo y dependencias de test en pom.xml
  4. Generación de tests por lotes — subagentes por paquete, cada uno lee la clase de producción y UNITTEST.md
  5. Recuperación automática — si hay archivos .class obsoletos o carreras de compilación, Bob los corrige
  6. Ejecución y validación — mvn test y corrección de fallos
  7. Informe de cobertura — JaCoCo con cobertura por clase

Solución de problemas y ayuda

Solución de problemas

API request failed — el chat muestra {"apiProtocol":"openai"}

Haz clic en Retry en la ventana de chat de Bob.

mvn test reporta "cannot find symbol" o clases faltantes

Archivos .class obsoletos de una ejecución anterior. Fuerza una recompilación completa:

mvn clean test

Fallos de inyección de mocks — NullPointerException

  • Asegúrate de que @ExtendWith(MockitoExtension.class) esté presente en la clase de test
  • Verifica que las anotaciones @Mock y @InjectMocks sean correctas
  • Comprueba que los mocks se inicialicen en @BeforeEach si no usas la extensión
  • Pide a Bob que revise la configuración de mocks

Los tests pasan individualmente pero fallan al ejecutarlos juntos

Los singletons de repositorio mantienen estado entre tests. Opciones:

  • Añadir métodos de reset a los repositorios, o usar reflexión para resetear instancias
  • Pedir a Bob que implemente aislamiento de tests adecuado
  • Considerar @TestInstance(Lifecycle.PER_CLASS) con limpieza adecuada

Informe JaCoCo no generado — no existe target/site/jacoco/

El informe necesita el goal jacoco:report explícitamente; mvn test solo no lo produce.

mvn clean test jacoco:report

La terminal de Bob muestra la versión incorrecta de Java

sdk use es por sesión de shell — no se aplica entre pestañas ni a la terminal que Bob abre por su cuenta. Ejecútalo en la terminal de Bob (macOS/Linux):

sdk use java 21.0.7-zulu

En Windows (PowerShell), asegúrate de que JAVA_HOME apunte a la instalación de Temurin 21 y reinicia la terminal.
