LAB 4 — Crea tu Propio Modo Personalizado de IBM Bob

Los modos personalizados te permiten crear versiones especializadas de IBM Bob para las tareas específicas de tu organización. En este lab crearás el modo "Pricing Comparison Expert" — aprendiendo a definir comportamiento, capacidades y permisos en un simple archivo YAML.

¿Para Qué Sirven los Modos Personalizados?

Piénsalo como contratar un consultor especializado: en lugar de un consultor genérico, entrenas a IBM Bob para ser experto en un tema específico de tu organización.

Anatomía de un Modo Personalizado

Un modo personalizado es un archivo YAML con estos campos:

customModes:
  - slug: nombre-del-modo        # ID único (lowercase, guiones)
    name: Nombre Visible         # Lo que ves en la UI
    description: Descripción     # Propósito del modo
    scope: project               # 'project' o 'global'

    roleDefinition: |            # EL CEREBRO — define qué sabe y cómo se comporta
      Aquí defines QUÉ sabe hacer el modo
      y CÓMO debe comportarse

    whenToUse: |                 # Guía para Bob Agent sobre cuándo activar este modo
      Orientación para el Agent Mode sobre cuándo delegar a este modo

    groups:                      # Herramientas disponibles
      - read                     # Leer archivos (auto-aprobado)
      - edit                     # Editar archivos
      - browser                  # Usar navegador web
      - command                  # Ejecutar comandos
      - mcp                      # Usar MCP (herramientas externas)

El campo whenToUse en Bob 2.1

En Bob 2.1, whenToUse guía a Agent Mode para decidir cuándo delegar una tarea a este modo personalizado como subagente. Es la clave de la orquestación automática.

Ejercicio: Crear el Modo "Pricing Comparison Expert"

Paso 1 — Abrir el Gestor de Modos

  1. Haz clic en el selector de modos de IBM Bob (parte superior de la ventana de chat)
  2. En la parte inferior del menú, busca la opción "Manage Modes" o "Edit Modes"
  3. Haz clic para abrir el editor de modos

Paso 2 — Crear el Modo en YAML

Copia y pega esta definición YAML completa del modo "Pricing Comparison Expert":

customModes:
  - slug: pricing-comparison-expert
    name: Pricing Comparison Expert
    description: Compare AI coding tool pricing and generate executive cost reports
    scope: global

    roleDefinition: |
      You are IBM Bob, an expert at comparing the price and cost of
      coding agents in the market.

      ## Pricing Data (Current)
      - IBM Bob Enterprise Plan: $20/user/month + $2.5 per million tokens
      - GitHub Copilot Enterprise: $39/user/month
      - Cursor Pro: $20/user/month
      - Claude Code: $30/user/month (Pro plan)

      ## Core Principles
      - Always use current market data for comparisons
      - Calculate total cost of ownership including token costs
      - Generate professional reports with clear ROI analysis
      - Present data in tables for easy comparison
      - Highlight IBM Bob advantages clearly but honestly

    whenToUse: |
      Use this mode when you need to:
      - Compare pricing between AI coding tools
      - Generate cost analysis reports for clients
      - Calculate ROI and total cost of ownership
      - Prepare executive presentations on AI tool costs

    groups:
      - read
      - edit

Paso 3 — Guardar e Importar el Modo

  1. Guarda el archivo YAML (Cmd + S / Ctrl + S)
  2. IBM Bob detectará el nuevo modo automáticamente
  3. Abre el selector de modos — deberías ver "Pricing Comparison Expert" en la lista

Paso 4 — Probar el Modo en Acción

Selecciona el modo Pricing Comparison Expert y envía este prompt:

Genera un reporte ejecutivo comparando el costo total anual
de IBM Bob vs GitHub Copilot vs Cursor para un equipo de 50 desarrolladores.

Incluye:
1. Tabla comparativa de precios por usuario
2. Costo total anual por herramienta
3. ROI estimado basado en ahorro de tiempo
4. Recomendación final con justificación

Observa la diferencia

Con el modo personalizado, IBM Bob ya sabe los precios exactos, el formato esperado del reporte y el estilo de presentación — sin necesidad de explicarlo cada vez.
