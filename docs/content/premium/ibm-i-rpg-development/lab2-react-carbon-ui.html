Lab 2 — Lista de artículos con React y Carbon

Una app React independiente que muestra artículos en una tabla con búsqueda, similar a la pantalla verde pero moderna y responsive.

4–10BobCoins estimados
~30minutos
Code / Agentmodo de Bob
UI ejecutableresultado

Qué vas a construir

Una app React independiente que muestra artículos en una tabla con búsqueda, similar a la pantalla verde pero moderna y responsive. No necesitas IBM i — usamos datos de muestra.

Prerrequisitos

  • Node.js 18+ instalado
  • Conocimiento básico de desarrollo web
Paso obligatorio — antes de cualquier prompt

Paso 0 — Dónde crear el proyecto

Este lab es independiente del bundle SAMCO: crea una carpeta nueva y vacía en tu equipo (por ejemplo article-list-lab/), ábrela en IBM Bob con File → Open Folder y cambia de Ask a Code Mode (Agent Mode) antes de empezar. El Paso 1 crea article-list-app/ dentro de esa carpeta.

  • La carpeta está vacía antes del Paso 1 — no necesitas el bundle SAMCO ni conexión a IBM i
  • El indicador de modo muestra Code / Agent

Paso 1 — Crea el proyecto React

IBM Bob · Agent

Bob crea Vite + TypeScript + Carbon en el directorio actual.

Pega en el chat de Bob

Crea un proyecto React + TypeScript con Vite y Carbon Design System.

Requisitos:
- Nombre: article-list-app
- Vite para desarrollo rápido
- TypeScript
- Instalar @carbon/react y @carbon/styles
- Estructura básica de carpetas

Créalo en el directorio actual.

Desde la terminal integrada, en este orden:

$ Terminal integrada

npm create vite@latest article-list-app -- --template react-ts

Entra a la carpeta que acaba de crearse:

$ Terminal integrada

cd article-list-app

$ Terminal integrada

npm install

$ Terminal integrada

npm install @carbon/react @carbon/styles

Paso 2 — Visualiza la pantalla verde

IBM Bob · Ask

Pide un dibujo ASCII de la subfile original para usarlo como referencia de UI.

Pega en el chat de Bob

@SAMCO/QDDSSRC/ART200D-Work_with_Article.DSPF

Muéstrame cómo se ve la pantalla de lista de artículos (SFL01).
Dibújala en ASCII art con:
- Cabecera "Work with Articles"
- Columnas (Opt, Id, Description, Fam, Del)
- 3 filas de ejemplo
- Manténlo simple

Paso 3 — Datos de muestra

IBM Bob · Agent

Genera un archivo TypeScript con diez artículos de ejemplo.

Pega en el chat de Bob

Crea un archivo TypeScript con 10 artículos de muestra basados en la estructura ART400.

Cada artículo debe tener:
- id (6 caracteres, ej. "ART001")
- description (50 caracteres)
- familyCode (3 caracteres, ej. "ELE")
- familyDescription (ej. "Electronics")
- salePrice (número)
- stock (número)

Guárdalo en: article-list-app/src/data/sampleArticles.ts

Paso 4 — Componente de lista

IBM Bob · Agent

Pide una DataTable Carbon de solo lectura con búsqueda.

Pega en el chat de Bob

Crea un componente React que muestre artículos en un Carbon DataTable.

Requisitos:
- Carbon DataTable
- Columnas: ID, Description, Family, Price, Stock
- Caja de búsqueda arriba
- Usar sampleArticles.ts
- Solo visualización, sin editar/borrar aún

Guardar en: article-list-app/src/components/SimpleArticleList.tsx

Paso 5 — App principal

IBM Bob · Agent

Conecta estilos Carbon y el componente en App.tsx.

Pega en el chat de Bob

Actualiza article-list-app/src/App.tsx para mostrar SimpleArticleList.

Requisitos:
- Importar estilos Carbon (@carbon/styles/css/styles.css)
- Importar SimpleArticleList
- Título "Article Management"
- Tema white de Carbon

Paso 6 — Ejecuta y prueba

Terminal integrada

Arranca Vite dentro de article-list-app/ y valida tabla, búsqueda y responsive.

$ Terminal integrada

npm run dev
  1. Abre http://localhost:5173
  2. Verifica la tabla de artículos
  3. Prueba la búsqueda
  4. Redimensiona el navegador para probar responsive
