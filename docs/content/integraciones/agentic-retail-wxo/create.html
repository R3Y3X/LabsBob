Paso 1 — Preparar la CLI de watsonx Orchestrate

La CLI de Orchestrate es un paquete de Python. Aislarla en un entorno virtual evita que choque con otras versiones instaladas en tu equipo. Bob crea el entorno, instala la CLI y confirma la versión.

Prompt para Bob — crear el entorno e instalar la CLI

El workspace de Bob es la raíz RoadShowBobStreamingIntegration.
Prepara mi entorno de watsonx Orchestrate usando la terminal integrada:

1. Entra a trackF/confluent_agents.
2. Ejecuta python3 --version. La CLI exige Python 3.11, 3.12 o 3.13.
   En macOS, python3 suele ser 3.9: usa python3.12 (o python3.11) para el venv.
3. Si ya existe .venv pero no tiene bin/activate (venv copiado de Windows),
   bórralo y recréalo. No reutilices un .venv de otro sistema operativo.
4. Crea un entorno virtual llamado .venv en esa carpeta.
5. Actívalo. Si estoy en Windows, usa .venv\Scripts\Activate.ps1 en vez de source.
6. Con el entorno activo, actualiza pip.
7. Instala el paquete ibm-watsonx-orchestrate.
8. Ejecuta "orchestrate --version" y dime qué versión quedó instalada.

Reglas:
- Mantén esta misma terminal para todo el laboratorio; no abras una nueva.
- Si algún paso falla, detente ahí y explícame el error. No improvises
  soluciones alternativas ni instales paquetes que no te pedí.

Desde la raíz del bundle, entra a trackF/confluent_agents. Comprueba la versión (python3 --version): si es menor que 3.11, sustituye python3 por python3.12 en estos comandos. Si .venv/bin/activate no existe, borra .venv y recréalo.

python3.12 -m venv .venv

Actívalo — en Windows PowerShell usa .venv\Scripts\Activate.ps1:

source .venv/bin/activate
python -m pip install --upgrade pip
pip install ibm-watsonx-orchestrate
orchestrate --version

✓ Checkpoint

  • Bob reporta una versión concreta de orchestrate, sin errores (Python del venv ≥ 3.11).
  • El prompt de la terminal muestra el prefijo (.venv).

Paso 2 — Preparar el archivo de configuración

El prompt de Bob revisa que Orchestrate ya esté en el .env de la raíz. Si lanzas el prompt con esas variables vacías, el check falla. Primero sacas URL y API key en IBM Cloud, las guardas en el archivo, y recién entonces pegas el prompt (está al final de este paso).

No pegues el prompt todavía

Haz en este orden: 1) copiar credenciales en IBM Cloud → 2) pegarlas en el .env de la raíz → 3) recién ahí el prompt de Bob. Kafka y ksqlDB ya vienen del Track D; aquí solo falta Orchestrate.

1. Cómo sacar URL y API key en IBM Cloud

Las dos salen del mismo sitio: la ficha de tu instancia watsonx Orchestrate, sección Credenciales. Cópialas antes de pulsar Iniciar watsonx Orchestrate.

  1. Entra a cloud.ibm.com. Arriba a la derecha, confirma que la cuenta es itz-saas-* (la de tu reserva TechZone), no tu cuenta IBM corporativa.
  1. Menú hamburguesa → Lista de recursos → abre tu instancia watsonx Orchestrate (nombre tipo wxo-…).
  1. Quédate en Manage. En la sección Credenciales copia URL y Clave de API. No uses la Service ID API Key de TechZone OUTPUTS: esa no es ORCHESTRATE_API_KEY.

2. Dónde pegarlas: el .env de la raíz

Abre en el editor de Bob el archivo .env que está en la raíz del bundle (RoadShowBobStreamingIntegration/.env), no dentro de trackF/confluent_agents. Completa estas dos líneas (Kafka y ksqlDB ya están del Track D):

VariableQué pegas
ORCHESTRATE_URLLa URL de Manage → Credenciales (forma https://api.<región>.watson-orchestrate.cloud.ibm.com/instances/<uuid>). Auth CLI: ibm_iam.
ORCHESTRATE_API_KEYLa Clave de API de esa misma pantalla. Nunca la Service ID de TechZone.

Copia los mismos valores de ORCHESTRATE_URL y ORCHESTRATE_API_KEY a participant-config.env (también en la raíz): el prompt de Bob hace source de ese archivo. No los escribas en un YAML ni los pegues en el chat.

RETAIL_MCP_TOOLKIT_NAME ya viene como retail_availability_mcp; no lo cambies.

Protege tu API key

La key vive solo en .env y participant-config.env de la raíz, que no se versionan. Nunca la subas al repositorio, no la muestres en una captura y no la pegues en el chat de Bob.

3. Recién ahora: prompt para Bob

Cuando ORCHESTRATE_URL y ORCHESTRATE_API_KEY ya estén guardadas (sin placeholders ni comillas vacías), pega este prompt en la misma conversación del Paso 1. Bob no te va a pedir las keys: las revisa en el archivo y sigue con el check, el personalize y el health del MCP.

Paso 3 — Activar la instancia y verificar el toolkit MCP

Activar el ambiente apunta la CLI a tu instancia. Acto seguido conviene comprobar que el toolkit MCP compartido esté registrado: sin él, los agentes se importan pero no pueden consultar inventario.

Prompt para Bob — activar el ambiente y listar el toolkit

Ya completé participant-config.env con la URL de mi instancia, el endpoint HTTP del MCP
y mi API key. Sigue en la misma terminal, desde la raíz del bundle
(source participant-config.env). Para orchestrate, el .venv está en
trackF/confluent_agents.

1. source participant-config.env
2. Registra el ambiente TechZone con IAM (no mcsp):
   orchestrate env add --name workshop --url "$ORCHESTRATE_URL" --type ibm_iam
   Si el ambiente "workshop" ya existe, salta este comando y sigue.
3. Actívalo usando la variable, nunca el valor literal:
   orchestrate env activate workshop --api-key "$ORCHESTRATE_API_KEY"
4. Ejecuta: orchestrate toolkits list

Reglas importantes:
- No imprimas ORCHESTRATE_API_KEY ni ORCHESTRATE_URL completas. Usa siempre las variables.
- Si env add avisa mcsp_v2, ignóralo: esta URL es ibm_iam (.cloud.ibm.com).
- Dime si aparece el toolkit "retail_availability_mcp" con la tool
  "get_sku_availability".
- Si NO aparece, detente y avísame. No ejecutes "orchestrate toolkits add".
source participant-config.env
source trackF/confluent_agents/.venv/bin/activate

Si el ambiente workshop ya existe, salta el siguiente comando:

orchestrate env add --name workshop --url "$ORCHESTRATE_URL" --type ibm_iam
orchestrate env activate workshop --api-key "$ORCHESTRATE_API_KEY"
orchestrate toolkits list

El toolkit no se registra desde tu equipo

El facilitador registra el MCP compartido una sola vez por instancia. Si retail_availability_mcp no aparece en la lista, detente y avísale. Registrarlo por tu cuenta con credenciales locales rompe el ambiente para el resto del grupo.
