Flujo del laboratorio

1 · Plan Plan Mode · PM — analizar el backlog de la Payment API, clasificar deuda técnica, vulnerabilidades y la nueva feature.
2 · Diseño Ask Mode · Arquitecto — revisar openapi.yaml, modelar el flujo de secuencia de POST /coupons/apply en draw.io.
3 · Código Agent Mode · Developer — corregir secreto hardcoded, inyección SQL, e implementar el endpoint de cupones.
4 · Test Agent Mode · QA — simular reporte SAST de SonarQube, ejecutar npm test hasta ver todos los tests en verde.
5 · Deploy Agent Mode · DevOps — optimizar Dockerfile a node:18-alpine, revisar y documentar el pipeline de GitHub Actions.
6 · Mantener Ask Mode · Seguridad — interpretar logs de Sentry/Datadog, configurar alerta PagerDuty y cerrar el ciclo con checklist de calidad.

Regla de oro

No pases a la siguiente fase sin un artefacto aprobado: plan con ítems clasificados → diagrama draw.io → tests en verde → imagen Docker construida → alertas configuradas.
